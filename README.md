# Git 练习课堂

这是全班共用的课程作业仓库。学生作为仓库协作者，通过各自的分支提交每次作业。每次提交都需要完成一次标准的团队协作流程：

> 接受协作邀请 → Clone 仓库 → 创建分支 → 修改文件 → Commit → Push → 发起 Pull Request

请不要直接修改其他同学的文件，也不要在仓库中上传密码、令牌、身份证号、手机号等敏感信息。

## 提交规则

1. 每位同学只修改自己在对应作业目录下的文件。
2. 分支名使用 `作业编号/学号-姓名`，例如 `hw01/20260001-张三`。
3. Commit 信息应说明做了什么，例如 `提交张三的 Git 练习`。
4. Pull Request 标题按当次作业说明填写。
5. 每次新作业都从最新的 `main` 分支创建一个新分支，不要重复使用旧分支。
6. Pull Request 成功创建即视为提交；教师审核后统一合并。
7. 不要把账号密码、访问令牌或其他敏感信息提交到仓库。

## 教师批改

教师通过 Pull Requests 页面检查：

- 文件是否放在正确目录；
- 文件名和内容是否符合要求；
- 是否使用了独立分支；
- Commit 信息是否清晰；
- 是否正确发起 Pull Request。
