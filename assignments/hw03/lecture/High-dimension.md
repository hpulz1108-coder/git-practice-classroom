# 第 3 讲：高维数据与维度灾难

> 主题负责人：zhang

## 一、课程定位

- **主题**：为什么生物医学数据经常“变量很多，样本很少”？
- **适用对象**：生物医学数据科学、医学统计或机器学习入门学习者
- **建议时长**：课堂 45 分钟；课后作业 60 分钟
- **主题类型**：数据理解与预处理、模型复杂度与验证策略
- **先备知识**：样本、特征、数据矩阵、训练集与测试集的基本概念

## 二、驱动问题

某研究团队获得 72 份白血病表达样本，每份测量了 7,129 个探针特征。团队成员认为：“特征越多，模型获得的信息越多，因此预测一定会更好。”

**驱动问题**：面对一个 `p >> n` 的生物医学数据集，我们是否应该保留全部特征？如何用距离、泛化误差和验证结果判断高维数据中的信号是否可靠？

## 三、核心问题

1. 什么是高维数据？如何用 `p` 和 `n` 描述数据规模？
2. 为什么高维会带来统计分析和机器学习困难？
3. 什么是维度灾难，它在距离计算、可视化、统计检验和模型泛化中如何表现？
4. 为什么生物医学研究中经常出现“大 p 小 n”？
5. 面对高维数据，降维、特征选择、正则化和交叉验证分别解决什么问题？

## 四、学习目标

完成本讲后，学生能够：

1. 用样本数 `n`、特征数 `p` 和数据矩阵解释高维问题。
2. 说出转录组、蛋白组、代谢组、医学影像和单细胞数据中的高维特征来源。
3. 解释维度升高后样本间距离为何变得不可靠，以及最近邻与最远邻差异为何可能缩小。
4. 解释“大 p 小 n”如何提高过拟合、假阳性和不稳定特征选择的风险。
5. 通过同一真实表达矩阵的探针子集比较距离分布、邻近关系和模型训练/测试表现。
6. 为高维生物医学任务提出至少一种降低复杂度或改进验证的策略，并说明其边界。

## 五、关键概念

### 5.1 什么是高维数据

- `n`：样本数量，例如患者、细胞、图像或组织样本数。
- `p`：特征数量，例如基因、蛋白、代谢物、像素或深度学习特征数。
- 当 `p` 很大，尤其是 `p >> n` 时，称为高维数据或“大 p 小 n”问题。
- 高维不只意味着“列很多”，还意味着数据结构、噪声、相关性和验证方式都需要重新考虑。

### 5.2 生物医学中的高维数据例子

| 数据类型 | 典型样本 | 典型特征 | 主要风险 |
|---|---|---|---|
| 转录组 | 患者或组织样本 | 几万个基因 | 特征高度相关、样本相对较少、多重检验 |
| 蛋白组 | 血液或组织样本 | 几千个蛋白 | 批次效应、检测下限、缺失值 |
| 代谢组 | 患者或体液样本 | 数百至数千个代谢物 | 峰识别误差、共线性、批次差异 |
| 医学影像 | CT、MRI 或病理图像 | 大量像素或深度特征 | 维度极高、标注成本高、分布偏移 |
| 单细胞数据 | 单个细胞 | 数千至数万个基因 | 噪声大、稀疏、细胞与患者层级混淆 |

### 5.3 维度灾难的主要表现

1. **距离退化**：在许多高维情形下，最近邻和最远邻的距离相对差异变小，距离排序不再像低维中那样有区分度。
2. **样本稀疏**：空间体积随维度增长，有限样本难以覆盖特征空间。
3. **过拟合**：模型可能利用噪声特征记住训练样本，在新样本上表现下降。
4. **多重检验增加**：同时检验的特征越多，偶然显著的结果越容易出现。
5. **可视化受限**：直接展示高维结构困难，降维图也可能丢失或扭曲信息。
6. **噪声掩盖信号**：无关特征、测量误差和批次效应可能淹没真正的生物学信号。

## 六、常见误区与失败模式

### 常见误区

1. 特征数量越多，信息量就一定越多。
2. 训练集准确率高，就说明模型学到了稳定的生物学规律。
3. 只要使用 PCA，就能自动解决过拟合和数据泄漏。
4. 高维数据中的每个特征都可以独立解释。
5. 降维图上相距较远的两组，就一定代表真实的生物学亚群。

### 失败模式

1. 在全体数据上先做特征筛选、标准化或 PCA，再划分训练集和测试集，造成信息泄漏。
2. 只报告训练集结果或只进行一次随机划分，导致性能估计不稳定。
3. 在 `p >> n` 时进行大量未经校正的单变量检验，产生假阳性。
4. 忽略特征相关性，把一组相关基因误当成许多独立证据。
5. 忽略患者、批次或实验平台结构，把批次差异当成疾病信号。

## 七、课堂 PBL 流程（45 分钟）

### 7.1 情境导入与初始投票（0–7 分钟）

学生独立回答：

> 同样使用 38 份训练样本时，纳入全部 7,129 个探针是否一定优于只使用较少探针？需要什么验证证据？

要求写下初始立场、理由，以及一个可能推翻自己判断的证据。

### 7.2 概念澄清：`p`、`n` 与数据矩阵（7–13 分钟）

学生判断下列数据的 `n` 和 `p`：

| 场景 | 一行代表 | 一列代表 | `n` | `p` |
|---|---|---|---|---|
| 患者转录组 | 患者/组织样本 | 基因表达量 | 患者数 | 基因数 |
| 单细胞表达矩阵 | 单个细胞 | 基因表达量 | 细胞数 | 基因数 |
| MRI 特征表 | 一次检查或患者 | 影像特征 | 检查数 | 特征数 |
| 蛋白组数据 | 患者/血液样本 | 蛋白丰度 | 样本数 | 蛋白数 |

进一步讨论：单细胞数据的“细胞数很多”是否自动意味着有效样本数很大？如果同一患者贡献了大量细胞，患者层级应如何处理？

### 7.3 实测数据练习 A：距离分布随维度变化（13–23 分钟）

固定全部 72 份真实表达样本，逐探针标准化；按种子 42 固定列序，取前 2、3、10、100、1,000 和 7,129 个实测探针，比较二维、三维与高维子集。

学生比较：

- 任意样本对之间的距离分布；
- 最近邻距离与最远邻距离；
- `(最远距离 - 最近距离) / 最近距离` 等相对差异指标；
- 随维度升高，距离是否仍然能清楚区分“近”和“远”。

**需要形成的证据**：一张不同维度的距离分布图或汇总表，并写出观察到的趋势及其适用条件。

### 7.4 实测数据练习 B：最近邻与最远邻（23–30 分钟）

对每个样本计算最近邻和最远邻，回答：

1. 二维、三维与高维数据中，最近邻和最远邻的距离差异如何变化？
2. 如果最近邻与最远邻的距离逐渐接近，基于距离的分类或聚类会受到什么影响？
3. 标准化、相关特征和不同距离度量是否可能改变观察结果？

### 7.5 实测数据练习 C：高维数据与过拟合（30–38 分钟）

使用原始 38/34 训练/测试划分和训练内标准化的 1近邻模型，逐步纳入更多已有的探针特征，并在原训练部分做重复交叉验证，比较：

- 训练集性能与测试集性能；
- 特征数增加前后的性能差距；
- 重复划分或交叉验证下结果的波动；
- 特征选择是否只在训练折内拟合，并将确定的列应用到验证/测试集。

**核心判断**：训练满分不等于泛化良好。纳入更多已有的探针特征可能带来有效信号，测试表现也可能提高；不能预设单调恶化，也不能把后续纳入分析的探针特征一概当作噪声。

### 7.6 证据链讨论与修正结论（38–45 分钟）

按照渐进披露顺序讨论：

- **证据 A**：特征很多，模型训练表现很高。此时可以下什么结论？
- **证据 B**：高维距离分布变得集中，最近邻和最远邻差异变小。原判断是否需要修正？
- **证据 C**：各维度训练分数均为满分，而测试表现不同。纳入更多已有的探针特征是否提高了本次测试表现？为什么仍不能宣称更多特征必然更好？
- **证据 D**：训练折内选择 20 个探针后，验证表现与探针集合如何变化？筛选是否每折都改善？嵌套调参和外部验证仍是后续方案，本课不声称已经实施。

最后学生完成：**“我现在认为特征越多不一定更好，因为……”**

## 八、课后作业

用自己的话解释：

> 为什么“特征越多”不一定意味着“模型越好”？

### 作业要求

1. 至少使用一个生物医学例子，如基因表达、蛋白组、影像或单细胞数据。
2. 解释 `p`、`n` 和 `p >> n` 的含义。
3. 至少说明两个风险：过拟合、多重检验、距离退化、噪声掩盖信号或数据泄漏。
4. 至少提出两种应对策略，如特征选择、降维、正则化、增加样本、交叉验证或批次校正。
5. 写出一个结论边界：即使经过高质量验证，也不能仅凭教学数据证明临床有效性或因果关系。

### 推荐作业结构

| 部分 | 引导问题 |
|---|---|
| 情境 | 你的生物医学数据中，样本和特征分别是什么？ |
| 机制 | 为什么高维使学习变难？ |
| 证据 | 哪个实测距离或验证结果支持你的解释？ |
| 策略 | 如何减少过拟合或提高结果稳定性？ |
| 边界 | 哪些结论仍然不能从该数据得到？ |

## 九、评价要点

- 能正确区分样本数 `n` 与特征数 `p`。
- 能把“维度灾难”解释为可观察的距离、稀疏性、检验数量或泛化问题，而不只是背诵定义。
- 能区分训练性能、验证性能和测试性能。
- 能识别高维分析中的数据泄漏、过拟合、批次效应和多重检验风险。
- 提出的应对策略与问题相匹配，并说明其代价和边界。
- 结论遵循“主张—证据—推理—边界”，不把高预测分数写成临床可用性。

## 十、教师提示

- 实测探针选列应固定随机种子，并让学生看到同一组样本在不同特征子集下的可比较结果。
- 不要把“高维一定失败”作为结论；关键是信号强度、样本量、特征相关性、模型复杂度和验证设计的共同作用。
- 解释最近邻/最远邻差异时，应强调结果依赖距离度量和数据分布，避免把本数据观察表述成所有高维数据的定律。
- 通过隐藏和逐步释放证据，让学生先提出“特征越多越好”的判断，再用测试性能和稳定性迫使其修正。

## 十一、收束问题

> 当我看到一个“变量很多”的生物医学数据集时，我首先应该问：样本真的足够吗？这些特征中有多少是信号、多少是噪声？我的验证设计能否证明模型面对新患者时仍然可靠？
