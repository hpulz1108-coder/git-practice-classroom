# 高维数据课的数据说明

本课使用Golub白血病真实表达数据。通过改变纳入分析的实测探针子集，比较距离、训练与测试表现及特征选择稳定性。

## 真实数据

`leukemia.csv` 于 2026-10-12 从 `../../4. Dimension-reduction/data/leukemia/leukemia.csv` 按字节复制，内容未变。原始下载时间为 2026-09-25。本地复制使本课可以独立发放；没有筛除样本、筛选探针或增添表达值。

- 数据：Golub 白血病微阵列表达，OpenML leukemia，ID 1104，version 1。
- 数据页面：<https://www.openml.org/d/1104>。
- 来源元数据：本目录 `openml-metadata.json`；在线 <https://www.openml.org/api/v1/json/data/1104>。
- ARFF 原件仍在第 4 讲 `data/leukemia/source/leukemia.arff`，下载地址 <https://openml.org/data/v1/download/53987/leukemia.arff>。
- 研究引用：Golub et al. (1999), *Molecular Classification of Cancer: Class Discovery and Class Prediction by Gene Expression Monitoring*, Science 286, 531–537，<https://doi.org/10.1126/science.286.5439.531>。本次检查依据本地源文件与元数据，未声称重新下载或独立核验论文全文。
- 授权：OpenML 的 licence 字段为 `Public`，保留原表述与来源，不能将其改写为 public domain 或 CC BY。
- CSV SHA-256：`915bce00295ac470f6bd970a4032730a170a080642a5da53ab0bcb0545156f19`。

| 字段 | 含义 | 是否模型输入 |
|---|---|---|

每行是一份表达样本，不能据此断言全部是已核验独立患者。缺少患者重复映射、中心、时间与批次字段，不补造配对关系，不宣称已排除批次效应。7,129 个探针不等于 7,129 个不同基因，更不等于 7,129 份独立信息。

实际检查：72 行、7,132 列；ALL 47、AML 25；训练部分 ALL 27、AML 11，测试部分 ALL 20、AML 14。72 个教学编号唯一；没有非有限值、常量探针或完全重复的表达行；探针列名唯一。数值范围 −28,400 至 71,369，负值 147,174 个、零值 1,615 个。数据为微阵列处理后的表达测量，完整物理单位和上游处理参数未在本地快照中列全；不得当作 RNA-seq 原始计数，也不直接取 log/log1p 或把非正值改成缺失。

CSV 延续原课程派生规则：保留 ARFF 全部行、探针列、数值及顺序；去除类别两端空格；CLASS 改名为 diagnosis；增加教学编号和划分标记。本次没有新增这些变换。

## 分析规则

实验A固定全部72份表达样本，逐探针z-score（ddof=0），使用种子42、7、2026打乱探针列序，分别取前2、3、10、100、1000、7129列。随机操作只决定使用哪些已有列，不生成表达值、不改变诊断。A-probe-orders.csv保留每种列序，二维/三维图的Probe 1–3对应种子42列序的前三个探针。

实验B使用历史38/34划分，标准化只在训练38份样本拟合；列序固定为种子42，比较2、10、100、1000、7129个探针的1近邻模型。另在原始训练记录内进行3折×3重复验证，比较全部探针和每个训练折内选择20个探针的流程；验证折不重新选择特征。

纳入更多已有的探针特征会同时改变分析使用的特征数与特征内容，不能断言后续纳入分析的列全是噪声，也不能把性能变化只归因于维度。全样本标准化只用于A的描述；预测性能来自B的训练内处理。历史测试集不是新开展的临床外部验证。
