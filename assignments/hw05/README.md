# HW05：统计检验与假设设计

## 本次要交什么

选择一个生物医学问题，完成一份《假设检验设计书》。你需要讲清楚：研究谁、比较什么、怎样提出假设、为什么选择这种统计方法，以及结果能支持什么结论。

预计用时：60–90 分钟。截止时间以课程群通知为准。

本次课后作业侧重研究设计，不要求另外寻找新数据或必须运行完整分析。没有实际数据时，请填写分析与报告计划，不要编造样本量、p 值或结果。课堂工作单用于随堂练习，可以作为附件提交，无需再写一份重复报告。

## 设计书需要包含的内容

1. **科学问题与研究设计**：明确研究对象、比较对象或主要解释变量、主要终点、测量时间和分析单位；说明是独立组、配对前后，还是其他设计。
2. **统计假设**：写出与研究问题对应的 H0、H1；说明检验的参数（例如均值差、比例差或相关系数）、显著性水平 α、双侧或单侧及理由。方向和主要终点应在查看结果前确定。
3. **变量类型**：列出结局变量、主要解释变量和必要协变量，说明它们是连续变量还是分类变量。
4. **统计方法与理由**：选择首选方法，说明它与设计和变量类型为什么匹配；列出关键假设、检查方式，以及至少一种备选方法和使用条件。不要只列检验名称。
5. **混杂与数据处理计划**：列出至少两个合理的潜在混杂因素，并说明如何控制或做敏感性分析；说明缺失值处理思路。若某因素没有测量，应列为限制，不能声称已控制。
6. **多重比较计划**：明确一个主要终点；如有多个指标、亚组或时间点，说明如何区分主要与探索性分析，以及是否需要校正。不要只挑显著结果报告。
7. **结果报告计划**：说明将报告的各组有效样本量、描述统计、效应量、95% 置信区间和 p 值，以及样本量或 power 的考虑。用本题情境各举一个 Type I、Type II error，并说明样本量、真实效应和测量噪声如何影响 power；不要求计算事后 power。
8. **结论边界**：说明统计显著性、实际或临床意义和因果结论的区别。用“主张—证据—推理—边界”写出结论表达计划；尚无数据时，用条件句说明将如何判断，不预设一定显著。

可以选择睡眠与血压、运动与静息心率、某指标与疾病状态等问题，但必须明确人群、变量和研究设计。若用课堂数据另选问题，应说明与课堂 `disease–thalach` 示例的区别。

## 提交格式

每位同学在自己的目录中提交一份设计书即可，推荐将 [TEMPLATE.md](TEMPLATE.md) 复制为个人目录中的 `README.md` 后填写：

```text
submissions/hw05/学号-姓名/
└── README.md                  # 填写完整的假设检验设计书
```

也接受 Word 或 PDF 设计书；使用这两种格式时，请保留一个简短的 `README.md`，写明姓名、学号、GitHub 用户名和设计书文件名。课堂工作单、实际分析代码和图表可作为附件，不是额外必交项。如果提交实际分析，请保留可核查的代码和输出，区分真实结果与计划。

评价重点是问题清楚、假设和方法对应、理由合理、风险与结论边界说明到位。不会因为使用复杂方法、获得显著结果或附加大量代码而自动加分。

请简要记录 AI 是否参与，以及你核查了哪些内容。不要上传数据副本、虚拟环境、缓存、压缩包、Office 临时文件或敏感信息，不要修改其他同学的目录。

## Git 提交流程

先确认当前修改已经保存并妥善提交，再从最新的 `main` 创建 HW05 分支：

```bash
git switch main
git pull origin main
git switch -c hw05/学号-姓名
```

完成设计书后，只暂存自己的目录：

```bash
git add submissions/hw05/学号-姓名/
git commit -m "提交姓名的 HW05 假设检验设计书"
git push -u origin hw05/学号-姓名
```

在 GitHub 创建 Pull Request：

- base：`main`；
- compare：自己的 `hw05/学号-姓名`；
- 标题：`HW05 假设检验 - 学号 - 姓名`。

创建 Pull Request 即视为提交，教师审核后统一合并。需要修改时，在同一分支继续 Commit 和 Push，原 Pull Request 会自动更新。

未完成 HW02、HW03 或 HW04 不影响开始 HW05。旧作业仍在各自分支与 Pull Request 中补交；如果原 Pull Request 已合并，需要补充时从最新 `main` 新建对应作业的补充分支和 Pull Request。不要把两次作业放在同一个 Pull Request 中。

## 提交前自查

- [ ] 已明确研究对象、比较对象、主要终点和分析单位；
- [ ] H0、H1、检验方向和统计方法相互对应；
- [ ] 已说明关键假设、备选方法和至少两个潜在混杂因素；
- [ ] 已说明缺失值、多重比较和结果报告计划；
- [ ] 已解释错误类型、power 和结论边界；
- [ ] 已区分计划、实际结果和 AI 提供的内容；
- [ ] 只提交自己的 HW05 目录，Pull Request 目标为 `main`。
