# 第 6 讲数据说明

## 为什么选择这份数据？

采用 Golub 白血病微阵列表达数据：同一批样本测量了数千个探针，可自然形成一个完整的多重检验家族。诊断包含 ALL（急性淋巴细胞白血病）和 AML（急性髓系白血病）。本课问题是“两种白血病亚型之间哪些表达特征值得进一步验证”，不是“患者与健康人之间有哪些疾病基因”。

`leukemia.csv` 沿用原课程第 4 讲的同一文件，本次从第 6 讲材料按字节复制；没有筛选样本、筛选探针、标准化或添加表达值。也可对照本仓库 [HW04 数据](../../../hw04/resources/data/leukemia/leukemia.csv)。数据共 72 份表达样本、7,129 个探针特征；加上三个说明字段，CSV 共 7,132 列。

| 字段 | 含义 | 本课用途 |
|---|---|---|
| sample_id | G001–G072，按源行序添加的教学编号 | 样本识别，不参与检验 |
| original_split | 原划分：前 38 行 train，后 34 行 test | 分别作为发现部分和留出验证部分 |
| diagnosis | ALL 或 AML | 分组变量，不属于探针家族 |
| 其余 7,129 列 | 源探针名称与处理后的表达测量，包含 AFFX 控制探针 | 每列进行一次组间比较 |

| 分析部分 | ALL | AML | 合计 |
|---|---:|---:|---:|
| 发现：train | 27 | 11 | 38 |
| 留出验证：test | 20 | 14 | 34 |
| 全部 | 47 | 25 | 72 |

一行是一份表达样本；现有字段不足以核验全部样本是否来自互不重复的患者，也不足以排除批次或中心混杂。7,129 个探针不等于 7,129 个不同基因，也不代表独立的生物证据。保留控制探针是为了透明地固定教学检验家族；后续生物学研究应另行预注册质量控制和探针注释方案。

## 数据处理与边界

- 表达值是处理后的微阵列强度，不是 RNA-seq 原始计数；完整单位与上游处理参数未在本地快照列全。
- 已核查无非有限值、无常数探针、无完全重复表达行，编号与探针列名唯一。数值范围为 −28,400 至 71,369，含负数。不要直接取 log/log1p，也不要把非正值当作缺失。
- 本课直接在原表达尺度上做逐探针双侧 Welch t 检验，不额外缩放。效应方向统一为 AML 减 ALL。不能将均值差称为 fold change。
- Welch 检验是教学近似，假定样本独立；小样本、偏态、异常值、相关探针和未测混杂会限制推断。多重校正不能修复无效的单项检验。
- `test` 是同一研究的历史留出样本，不是新招募的外部独立队列。必须先在发现部分锁定候选，再访问其验证结果。

## 已知真值的统计实验

教学要求包含全零效应和部分有信号的模拟实验。Notebook 在运行时生成独立正态变量；它们不是这份 CSV 的一部分，不是实测基因，也不是新患者。模拟之所以需要，是因为真实数据中不知道哪些零假设为真，无法直接数出真实假阳性。模拟矩阵不作为原始数据交付；运行表、图和缓存统一写入项目根目录 `.tmp/multiple-test/`。
