# HW06：多重检验校正——从显著到值得验证

## 本次任务

使用课程提供的 Notebook，比较原始 p 值、Bonferroni 和 Benjamini–Hochberg（BH）校正的结果，完成一份实验报告，并保存查看留出验证结果之前锁定的候选名单。

核心问题：同时检验了数千个探针后，哪些差异值得进一步验证？请用错误控制、效应大小和验证证据解释你的判断。

课堂约 45 分钟，课后约 60 分钟。截止时间以课程群通知为准。HW02–HW05 可继续分别补交，不影响开始 HW06。

## 数据与固定协议

真实数据有 72 份表达样本、7,129 个微阵列探针。ALL 和 AML 都是白血病亚型，没有健康对照；探针不等于独立基因。

| 项目 | 本次规定 |
|---|---|
| 发现部分 | `original_split=train`：ALL 27、AML 11 |
| 发现检验家族 | 全部 7,129 个探针；排除三个说明字段 |
| 单项检验 | 双侧 Welch t；H0：AML 与 ALL 的总体均值相等 |
| 差值方向 | AML−ALL |
| 方法比较 | 同一组原始 p，分别按 raw / Bonferroni / BH adjusted p≤0.05 计数 |
| 候选规则 | 发现部分 BH 显著者，按 raw p 升序、probe 名升序取前 10 个；不足 10 则取全部 |
| 留出部分 | `original_split=test`：ALL 20、AML 14 |
| 验证规则 | 只检验锁定候选，在候选家族内 Bonferroni≤0.05 且效应方向相同 |

先记录协议，再分析发现部分；先锁定候选与验证判据，再查看 test。不得根据验证结果更换候选。保留当前表达尺度，不直接取 log，也不把零或负值当作缺失。均值差不能写成 fold change。

## 需要完成的内容

### 一、课堂实验 A/B：理解错误控制与漏检

- A：1,000 个变量都没有真实差异，比较一次运行和 1,000 次重复的发现数、FWER 和 FDR；全零实验的 power 记为 N/A。
- B：前 100 个变量有真实差异，比较 δ=1.0 与 δ=0.5，观察三种方法的假发现与检出力。
- 在报告中保留 A/B 的关键汇总与解释。课堂已完成者可使用自己记录的课堂表，无需再次运行模拟；没有记录者可用 Notebook 补跑。无需逐条提交所有模拟结果。

### 二、课后实验 C：完整完成 C1–C4

1. **C1 完整家族比较**：在 train 中检验全部探针，记录家族大小、Bonferroni 的原始 p 阈值，以及三种方法的发现数；保留原始 p 值直方图。
2. **C2 错误流程审阅**：比较完整家族校正与“先挑最小 p 的 20 个再校正”的结果，至少记录同一探针的一组对照，解释后者为何不支持原家族的控制目标。
3. **C3 锁定候选**：记录固定候选规则，在查看 C4 前保存候选名单和发现方向。选择一个候选，报告两组 n、均值、AML−ALL 均值差、逐项 95% CI、Cohen d、raw p 与两种 adjusted p。
4. **C4 留出验证**：报告候选家族大小、通过预定判据的数量，以及上述候选的验证差值、Bonferroni adjusted p 和方向。用 80–120 字写“主张—证据—推理—边界”。

逐项 95% CI 不是整个家族的同时置信区间，也未对筛选进行选择校正。真实数据不知道单项真值，不能计算真实假发现数或真实 power。test 是同一研究的历史留出样本，不能称为新招募的外部独立队列；若以前课程已看过相关结果，应如实说明。

### 三、概念与方法短答

- 分别解释 p-value、adjusted p-value、FDR；每项给一个组学或临床例子，以及一个不能作出的错误解释。
- 区分 FWER、一次实验的 FDP 和长期 FDR；说明为什么应先逐次算 FDP 再平均，不能用平均 V/平均 R 替代。
- 解释 1,000 次全零检验为什么平均可能出现约 50 个原始显著结果，以及“期望数量约 50”是否要求检验相互独立。
- 说明本次 `bh` 是 BH adjusted p，不是自动计算的 Storey q-value，也不是单项结果为假的概率。
- 分别以探索性组学筛选和确认性临床终点举例选择错误控制目标，解释取舍。
- 说明校正后为什么还需要效应、CI、生物学证据与独立验证，以及多重校正不能证明的结论。

可选手算可替代一个方法例子：p 值为 `[0.001, 0.009, 0.020, 0.040, 0.200]`，m=5，阈值 0.05，计算 Bonferroni adjusted p、BH 排序阈值及最大满足位置 k。该题为教学例子，不是真实探针结果。
