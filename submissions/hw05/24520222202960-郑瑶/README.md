## 一、科学问题与研究设计

- 用一句话写出科学问题：在课堂提供的四中心心脏病数据所涉及的受试者中，有心脏病证据组与无心脏病证据组的总体平均最大运动心率是否不同？
- 研究对象与纳入范围：课堂四中心心脏病数据中的受试者。主要两组比较计划纳入疾病状态 disease 和最大运动心率 thalach 均有记录的受试者，并报告因这些变量缺失而未纳入的人数。
- 比较对象或主要解释变量：疾病状态 disease；比较 disease=1（原始疾病等级 num>0，有心脏病证据）与 disease=0（num=0，无心脏病证据）两组。两组由不同受试者组成，没有同一人的前后配对关系。
- 主要终点及单位：最大运动心率 thalach，单位为次/分；主要比较两组的总体均值。
- 测量时间或观察窗口：使用数据中记录的单次评估信息，其中 thalach 为运动测试中的最大心率；现有材料未提供具体测量日期，也没有同一受试者的前后随访记录。
- 分析单位：每名受试者；数据每行代表一名受试者。来源中心的差异将在后续分析计划中考虑。
- 研究设计（观察性/实验性，独立组/配对等）：观察性横断面研究，按疾病状态进行独立两组比较。
- 计划使用的数据来源；没有数据时说明未来如何收集：使用仓库中的 assignments/hw05/resources/data/heart-disease-hypothesis.csv，并依据同目录 README.md 理解字段和分组编码。

## 二、统计假设

- 待检验的参数及其定义：Δ = μ₁ − μ₀，其中 μ₁ 是 disease=1 组的总体平均最大运动心率，μ₀ 是 disease=0 组的总体平均最大运动心率；单位为次/分。
- H0：Δ = 0，即两组总体平均最大运动心率相同。
- H1：Δ ≠ 0，即两组总体平均最大运动心率不同。
- 显著性水平 α：0.05。
- 双侧或单侧及理由：采用双侧检验，因为研究问题是两组平均最大运动心率是否不同，没有预先限定疾病组只能更高或更低。
- 哪些选择需要在查看结果前确定：主要终点为 thalach、疾病分组方式、检验两组总体均值差、H0和H1的定义、显著性水平 α=0.05、采用双侧检验、主分析方法、纳入规则以及缺失值的处理规则。

## 四、统计方法与依据

- 首选统计方法：Welch 两独立样本 t 检验，双侧检验，显著性水平 α=0.05。
- 为什么适合本研究设计和变量类型：本研究比较 disease=1 与 disease=0 两组不同受试者的最大运动心率。thalach 为连续变量，disease 为二分类变量，研究目标是比较两组总体平均值，因此使用独立样本均值比较方法。Welch t 检验不要求两组方差相等。
- 关键假设与检查方式：每名受试者只贡献一次测量，且受试者之间的观察相互独立。根据数据说明确认每行代表一名受试者，并检查 record_id 是否重复；若发现重复记录，需先查明原因并重新确定分析单位。另检查两组 thalach 的分布、样本量和极端值，评估均值比较是否容易受到偏斜或极端值影响。Welch t 检验不要求两组方差相等，但仍需考虑独立性和数据分布对推断的影响。
- 至少一种备选方法及其适用条件；若更换方法，解释对象是否改变：若 thalach 分布明显偏斜或存在极端值，可将 Mann–Whitney U 检验作为敏感性分析。该方法比较两组数据的秩次或分布位置，不一定等同于比较总体均值，因此解释对象会改变。也可将 age、sex 和 site 纳入线性回归作为调整分析，用于考察考虑这些已测量因素后，disease 组间平均差是否改变；site 应作为分类变量处理。

- 是否还有其他指标、亚组或时间点：本研究不预先指定其他主要指标、亚组或时间点；若探索年龄、性别或中心的分层结果，将明确标为探索性分析。
- 多重比较控制及探索性结果的报告计划：主要推断只针对预先指定的 thalach 组间比较。其他指标或亚组分析均标为探索性，完整报告分析过的结果，不只挑选显著结果；若开展多个次要假设检验，将采用 Holm 方法校正 p 值，并同时报告未校正结果与校正方法。

## 六、错误类型、power 与结果报告计划

- 本研究中的 Type I error：在两组总体平均最大运动心率实际上相同的情况下，由于样本波动而拒绝 H0，错误地认为 disease=1 组与 disease=0 组的平均最大运动心率不同。
- 本研究中的 Type II error：两组总体平均最大运动心率实际上存在差异，但由于样本量不足、真实差异较小或测量噪声较大，未能拒绝 H0，因而没有检出真实差异。
- 样本量、真实效应、测量噪声如何影响 power：在其他条件相同的情况下，样本量越大，通常越容易发现真实差异，power 越高；真实效应越大，越容易被检出，power 越高；最大运动心率的测量误差和个体差异越大，数据越分散，越难识别组间差异，power 通常越低。
- 样本量或 power 如何考虑（可定性说明，无需计算事后 power）：正式研究前应根据预期的最小实际重要差异、心率的预期变异程度、显著性水平 α=0.05 和预设的目标 power（例如 80% 或 90%）进行样本量规划，并考虑缺失数据和可能的退出。当前作业是研究设计计划，不进行事后 power 计算，也不根据未达到显著性来反推没有效应。
- 各组有效样本量和描述统计将如何报告：报告 disease=1 和 disease=0 两组的有效样本量 n、thalach 的均值和标准差；若分布明显偏斜或存在极端值，同时报告中位数和四分位距，并说明缺失值导致的排除人数。
- 计划报告哪一种效应量，如何定义方向与单位：主要报告两组平均最大运动心率差 Δ̂ = 疾病组样本均值 − 无疾病组样本均值，单位为次/分。差值为正表示疾病组样本平均最大运动心率较高，差值为负表示较低。
- 95% 置信区间和 p 值将如何报告和解释：报告两组平均最大运动心率差 Δ̂=疾病组样本均值−无疾病组样本均值的 95% 置信区间和双侧 p 值，置信区间的单位为次/分。由于 0 表示两组总体平均值相同，在同一双侧 α=0.05 检验框架下，置信区间不包含 0（对应 p<0.05）时，认为数据提供了两组总体平均值不同的统计证据，拒绝 H0；若置信区间包含 0（对应 p≥0.05），则未拒绝 H0，表示当前证据不足。解释时还将结合区间宽度、效应量大小和实际意义，不能仅凭 p 值作因果结论。
- 未拒绝 H0 时，为什么不能直接说“证明没有效应”：未拒绝 H0 只表示当前样本和分析方法没有提供足够证据拒绝无均值差假设，可能是差异确实很小，也可能是样本量不足、测量噪声较大或估计不精确；因此不能把“没有检出差异”直接等同于“证明没有效应”。

## 七、结论表达与边界

无实际数据时，请用“如果……则……”表达计划，不要预设研究一定显著。

- 主张：如果预先指定的双侧检验提供了足够的统计证据，则认为本数据支持 disease=1 组与 disease=0 组的总体平均最大运动心率不同；如果证据不足，则认为当前数据不足以支持两组总体平均值不同。
- 证据：依据两组有效样本量、thalach 的描述统计、疾病组减去无疾病组的平均差、95% 置信区间和双侧 p 值，并结合调整年龄、性别和来源中心后的敏感性分析结果进行判断。
- 推理：如果 p<0.05 且 95% 置信区间不包含 0，则认为数据提供了两组总体平均最大运动心率不同的统计证据；根据均值差的正负判断疾病组的估计平均值较高或较低。如果 p≥0.05，则未拒绝 H0，只能说当前证据不足以支持两组总体平均值不同。
- 边界：本研究是观察性横断面研究，结果只能说明疾病状态与最大运动心率之间的统计关联，不能证明疾病导致最大运动心率改变，也不能直接推广到所有人群或临床治疗效果。
- 如何区分统计显著与生物学/临床重要性：统计显著性主要由 p 值和置信区间判断；生物学或临床重要性则要结合平均差的大小、95% 置信区间、专业上认为有意义的差异界限以及实际应用背景判断。统计显著的很小差异不一定具有临床重要性。
- 研究设计是否支持因果推断，为什么：不支持。研究没有随机分配疾病状态或干预，且是观察性横断面数据，疾病状态、最大运动心率和潜在混杂因素是在同一观察窗口记录的，无法确定时间先后，也不能排除混杂和选择偏差。
- 若要支持更强的结论，还需要什么证据：若要支持更强的因果结论，需要设计合理的纵向研究，明确时间顺序，充分测量并控制重要混杂因素，并在独立样本中重复验证。若研究的是某项可实施的治疗或干预效果，可考虑随机对照试验。
