## 一、科学问题与研究设计

- 用一句话写出科学问题：在纳入的受试者中，血清胆固醇水平与静息收缩压是否存在统计关联？
- 研究对象与纳入范围：研究对象为 `resources/data/heart-disease-hypothesis.csv` 中的受试者。纳入 `chol`（血清胆固醇）和 `trestbps`（静息收缩压）均有有效记录的受试者；两项指标任一缺失者不进入主要相关性分析。除非另有预先说明，不按 `disease` 或 `site` 排除受试者。
- 比较对象或主要解释变量：本研究不比较两个分类组，主要考察连续变量血清胆固醇 `chol` 与静息收缩压 `trestbps` 的关联。为便于描述，可将 `chol` 作为主要解释变量、`trestbps` 作为主要结局变量，但该横断面设计不支持把这种方向解释为因果方向。
- 主要终点及单位：静息收缩压 `trestbps`，单位为 mmHg；主要关联变量为血清胆固醇 `chol`，单位为 mg/dL。主要效应量为两者的 Pearson 相关系数 (\rho)（补充报告 Spearman 秩相关系数作为稳健性分析）。
- 测量时间或观察窗口：使用同一次临床检查记录中的 `chol` 和 `trestbps` 测量值。研究为单次横断面观察，没有前后随访窗口；若原始资料包含具体日期，将记录并核对两项测量是否属于同一次检查。
- 分析单位：每名受试者一条记录；每条记录提供一对血清胆固醇和静息收缩压测量值。
- 研究设计（观察性/实验性，独立组/配对等）：观察性横断面研究。没有随机分配或研究者干预，也不是独立组比较；每名受试者贡献一对同时测量的连续变量。这里的“一对数据”用于相关分析，不等同于同一患者干预前后的配对比较。
- 计划使用的数据来源；没有数据时说明未来如何收集：计划使用 `resources/data/heart-disease-hypothesis.csv` 中的 `chol` 和 `trestbps` 字段。正式分析前检查字段单位、取值范围、重复记录和缺失情况；不把缺失值当作 0。若需要新数据，则在同一次标准化体检中测量血清胆固醇和静息收缩压，记录单位、测量仪器、是否空腹、测量前休息时间、用药情况及测量时间。

## 二、统计假设

- 待检验的参数及其定义：主要参数为总体 Pearson 相关系数 \(\rho\)，表示目标人群中血清胆固醇与静息收缩压线性关联的方向和强度。补充参数为 Spearman 总体秩相关系数 \(\rho_s\)，用于评价单调关联。若报告线性回归，也将定义为每增加 1 mg/dL `chol`，`trestbps` 平均改变的斜率 \(\beta_1\)（单位：mmHg/(mg/dL)）。
- H0：\(\rho=0\)（等价地，在预先指定的线性关联分析中 \(\beta_1=0\)）；总体中血清胆固醇与静息收缩压没有线性关联。
- H1：\(\rho\ne0\)（等价地 \(\beta_1\ne0\)）；总体中血清胆固醇与静息收缩压存在非零线性关联。
- 显著性水平 α：0.05。
- 双侧或单侧及理由：双侧检验。科学问题询问“是否有关联”，没有在查看结果前足够依据预先限定关联方向，因此同时考虑正关联和负关联。
- 哪些选择需要在查看结果前确定：主要终点为 `trestbps`，主要解释变量为 `chol`；主要效应量为 Pearson \(\rho\)；采用双侧检验且 α=0.05；Spearman 相关、分层分析和回归调整属于预先标明的补充或敏感性分析；缺失值处理规则、异常值核查规则及主要协变量也应在查看 p 值前确定。

## 四、统计方法与依据

- 首选统计方法：在完成散点图和数据质量检查后，计算 Pearson 相关系数及其 95% 置信区间，并进行双侧相关性检验；同时用散点图显示观测分布。若将 `chol` 作为解释变量，可补充报告简单线性回归斜率及其 95% 置信区间，但回归方向只表示建模约定，不表示因果关系。
- 为什么适合本研究设计和变量类型：`chol` 和 `trestbps` 都是连续变量，每名受试者提供一对同时测量值，Pearson 相关适合检验总体线性关联，且不需要把连续变量任意分组。回归斜率可以把关联表示为胆固醇每增加 1 mg/dL 时静息收缩压的平均变化，便于解释单位和方向。
- 关键假设与检查方式：检查两变量是否为数值型、单位是否一致、是否存在明显录入错误；用散点图检查线性趋势、弯曲关系和离群点；检查极端值对相关系数的影响；若使用经典 Pearson 检验，关注观测是否近似独立以及异常值是否过度影响结果。独立性主要依赖每名受试者一条记录和研究设计，不能仅靠统计检验保证。必要时按 `site` 检查分布差异。
- 至少一种备选方法及其适用条件；若更换方法，解释对象是否改变：Spearman 秩相关是备选方法，适用于存在离群值、明显偏态或单调但非线性的关系；它检验的是秩次的单调关联，解释对象会从原始测量值的线性关联变为单调关联。若散点图显示明显非线性，可使用变换、分段回归或预先说明的非线性模型，但应报告模型改变及其解释对象。

## 六、错误类型、power 与结果报告计划

- 本研究中的 Type I error：实际上总体中 `chol` 与 `trestbps` 没有线性关联，却因样本随机波动得到 p<0.05，错误地声称存在关联。
- 本研究中的 Type II error：实际上总体中存在有意义的关联，但样本量不足、关联较弱或测量噪声较大，未能拒绝 H0，错误地认为没有发现关联。
- 样本量、真实效应、测量噪声如何影响 power：在 α 固定时，样本量越大，越容易检测到给定大小的真实相关；真实相关越强，power 越高；血压或胆固醇测量误差、短期生理波动和录入误差会削弱观察到的相关并降低 power。样本量很大时很小的关联也可能统计显著，因此还要结合效应量和临床意义。
- 样本量或 power 如何考虑（可定性说明，无需计算事后 power）：在正式收集数据前，根据预期的最小有意义相关系数、α=0.05、双侧检验和目标 power（例如 80%）估算样本量，并预留缺失和无效记录。现有课堂数据若仅用于练习，则报告实际有效样本量，不进行事后 power 计算来替代不确定性评估。
- 各组有效样本量和描述统计将如何报告：相关分析没有比较组；报告 `chol` 和 `trestbps` 各自的有效 n、均值和标准差；若分布偏态或受离群值影响，同时报告中位数和四分位距，并报告缺失数量。按 `site` 或 `sex` 的补充分析报告各层有效 n。
- 计划报告哪一种效应量，如何定义方向与单位：主要报告 Pearson \(r\)（样本相关系数）及其 95% CI，方向定义为 `chol` 增大时 `trestbps` 倾向增大为正，倾向减小为负；补充报告 Spearman \(r_s\)。若报告回归，斜率单位为每增加 1 mg/dL `chol` 对应的平均 mmHg 变化。
- 95% 置信区间和 p 值将如何报告和解释：报告相关系数或斜率、95% CI、双侧 p 值和有效样本量，并说明 CI 表示在所作模型和抽样假设下参数不确定性的范围。p 值用于衡量与 H0 相容的证据强弱，不能表示关联为真的概率，也不能单独表示临床重要性。
- 未拒绝 H0 时，为什么不能直接说“证明没有效应”：未拒绝 H0 可能是关联确实很小，也可能是样本量不足、测量噪声较大或估计不精确；只有结合效应量和 95% CI，若区间足够窄且排除了预先定义的有意义关联，才能说数据未显示出具有明确意义的关联。

## 七、结论表达与边界

无实际数据时，请用“如果……则……”表达计划，不要预设研究一定显著。

- 主张：如果主要分析得到的 Pearson 相关系数及其 95% CI 与预先定义的有意义关联一致，且双侧 p<0.05，则主张本研究样本中血清胆固醇与静息收缩压存在统计关联；如果不满足，则表述为“未观察到足够证据支持预先定义的线性关联”。
- 证据：依据完整案例的有效样本量、散点图、相关系数或回归斜率、95% CI 和双侧 p 值，并结合 Spearman 和协变量调整敏感性分析的一致性。
- 推理：若估计值方向稳定、置信区间排除 0 且结果在合理的敏感性分析中保持一致，则数据与非零关联相容；若 CI 较宽或不同分析不一致，则结论应保持不确定。
- 边界：本研究是观察性横断面研究，可能受到年龄、性别、中心、药物、生活方式和选择偏倚影响；测量误差和缺失值也可能改变估计。关联不等于因果，不能据此断言胆固醇升高导致静息收缩压升高，也不能据此推断治疗效果。
- 如何区分统计显著与生物学/临床重要性：同时查看效应量、95% CI 和预先规定的实际重要阈值，而不只看 p 值。样本量很大时很小的关联也可能显著；只有达到具有实际意义的效应大小且不确定性可接受，才可进一步讨论临床意义。
- 研究设计是否支持因果推断，为什么：不支持。研究没有随机分配、暴露发生顺序和混杂控制也不充分，且两个指标在同一时间点测量，因此只能进行关联推断。
- 若要支持更强的结论，还需要什么证据：需要前瞻性纵向研究或设计良好的干预研究，明确测量顺序，收集并控制药物、生活方式和其他重要混杂因素，采用标准化、重复的血压和胆固醇测量，并在独立人群中重复验证。
