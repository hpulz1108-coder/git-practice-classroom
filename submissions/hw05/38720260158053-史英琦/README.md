## 一、科学问题与研究设计

- 用一句话写出科学问题：在课程提供的四中心心脏病横断面数据中，疾病组与非疾病组受试者的最大运动心率 `thalach` 是否存在差异？
- 研究对象与纳入范围：课程数据 `resources/data/heart-disease-hypothesis.csv` 中的受试者；主要模型纳入 `disease`、`thalach` 及预先指定协变量均可判定的记录。此课堂样本不视为所有心脏病患者的代表样本。
- 比较对象或主要解释变量：`disease=1` 与 `disease=0`；数据说明中前者为原始等级 `num>0`，后者为 `num=0`。
- 主要终点及单位：最大运动心率 `thalach`，连续变量，单位次/分。
- 测量时间或观察窗口：单次横断面测量；没有纵向或重复测量信息。
- 分析单位：每名受试者一行；如发现重复记录须先核查，不能当作独立个体。
- 研究设计（观察性/实验性，独立组/配对等）：观察性横断面独立组比较，非随机分配，不是同一患者前后配对设计。
- 计划使用的数据来源；没有数据时说明未来如何收集：课程提供的四中心心脏病课堂数据；`site` 是来源中心，不是处理组；不补造未测量信息。

## 二、统计假设

- 待检验的参数及其定义：多元线性回归中 `disease` 的系数 β_D，表示控制年龄、性别和来源中心后疾病组减非疾病组的平均 `thalach` 差，单位次/分。
- H0：β_D = 0，即调整后两组平均 `thalach` 无差异。
- H1：β_D ≠ 0，即调整后两组平均 `thalach` 存在差异。
- 显著性水平 α：0.05。
- 双侧或单侧及理由：双侧。虽可能预期疾病组心率较低，但不能保证方向；双侧检验允许发现任一方向的差异。
- 哪些选择需要在查看结果前确定：主要终点、`disease` 编码及对比方向、协变量、双侧检验、α 和稳健标准误方案；不根据结果显著性更改。

## 四、统计方法与依据

- 首选统计方法：多元线性回归 `thalach ~ disease + age + sex + site`；对 `disease` 系数采用 HC3 异方差稳健标准误，双侧检验并计算 95% 置信区间。
- 为什么适合本研究设计和变量类型：结局为连续变量，解释变量比较两个独立观察组。回归可估计控制已记录年龄、性别和中心后的平均差；`site` 作固定效应。HC3 可减轻异方差对标准误推断的影响，但不能解决混杂或偏倚。
- 关键假设与检查方式：核查每人一行、编码、缺失、各组/中心人数；用图形和残差检查年龄线性关系、异方差、离群或高影响点；检查两组在中心和年龄范围内的重叠。若中心内缺少组间重叠，估计可能依赖外推；稳健标准误不能弥补小样本或模型错误。
- 至少一种备选方法及其适用条件；若更换方法，解释对象是否改变：Welch 两独立样本 t 检验可作未调整比较，适用于独立组连续结局且不要求方差相等，但估计的未调整均值差不同于主要调整后差。若年龄非线性可作样条敏感性分析；若极端值影响大可补充稳健回归或自助法区间，并说明参数解释可能变化，不挑显著结果。

| 潜在混杂因素 | 为什么可能影响本题关联 | 控制或敏感性分析计划 |

- 是否还有其他指标、亚组或时间点：无其他确证性终点；必要的中心或性别分层仅作探索，不据此改写主要结论。

## 六、错误类型、power 与结果报告计划

- 本研究中的 Type I error：真实调整后均值差为零，却因抽样波动拒绝 H0 并报告关联。
- 本研究中的 Type II error：实际存在有意义差异，却因样本量不足、组间不平衡、噪声或估计不精确而未能拒绝 H0。
- 样本量、真实效应、测量噪声如何影响 power：其他条件相同时，样本量和真实差异增大通常提高 power；测量误差、个体差异及缺失造成的有效样本减少会降低精度和 power。
- 样本量或 power 如何考虑（可定性说明，无需计算事后 power）：不编造样本量、效应或事后 power。前瞻研究应依据有意义的最小差异、标准差、α=0.05、目标 power、组别比例、中心差异和预计缺失率估算样本量；课堂分析报告实际人数和区间精度。
- 各组有效样本量和描述统计将如何报告：报告总记录数、两组有效人数及主要模型纳入人数；分组报告 `thalach` 均值、标准差，可补充中位数和四分位数，并描述年龄、性别和中心构成。具体数值待实际分析核实。
- 计划报告哪一种效应量，如何定义方向与单位：调整后均值差（疾病组减非疾病组），单位次/分；正值表示疾病组较高，负值表示较低。未调整差异另作描述。
- 95% 置信区间和 p 值将如何报告和解释：报告 HC3 下的调整后差、95% CI 和双侧 p 值。区间表示与数据及模型相容的效应范围；p 值不是 H0 为真的概率，也不代表效应大小或临床价值，解释侧重估计及区间。
- 未拒绝 H0 时，为什么不能直接说“证明没有效应”：未拒绝仅表示证据不足，不能证明真实差异为零；需结合区间能否排除实际重要差异及其精度判断。

## 七、结论表达与边界

无实际数据时，请用“如果……则……”表达计划，不要预设研究一定显著。

- 主张：如果模型支持非零差异，则报告本课堂样本中调整后的关联及估计方向和幅度；如果未拒绝 H0，则说证据不足，不说证明无差异。
- 证据：两组有效人数、描述统计、调整后均值差、HC3 稳健 95% CI、双侧 p 值、模型诊断和缺失处理记录。
- 推理：系数估计模型协变量相同时两组平均 `thalach` 差；若区间不跨 0 且 p<0.05，结果与非零关联相符，但实际意义仍需看效应幅度和区间。
- 边界：横断面观察性数据没有随机化及明确时间顺序，仍可能有未测混杂、选择偏倚和测量差异，不能证明疾病导致心率变化或推出治疗效果；课堂样本也不自动代表其他人群。
- 如何区分统计显著与生物学/临床重要性：将估计值及区间与有依据的最小重要差异比较。统计显著不等于临床重要；不显著且区间宽也不能排除重要差异。数据未给出临床阈值。
- 研究设计是否支持因果推断，为什么：不支持；调整不能排除未测混杂、反向因果或选择偏倚。
- 若要支持更强的结论，还需要什么证据：需更具代表性的多中心样本、标准化测量、补充用药/吸烟/体能/合并症信息和独立验证。因果问题还需明确时间顺序和合理识别设计；治疗问题可考虑符合伦理的随机试验或严谨纵向研究。
