## 一、科学问题与研究设计

- **用一句话写出科学问题**：在四个中心接受运动负荷试验的成年人中，被判定患有冠心病者的最大运动心率，是否与未患病者不同？
- **研究对象与纳入范围**：四个中心共 920 名接受运动试验与心脏评估的成年人（Cleveland 303、Hungary 294、VA Long Beach 200、Switzerland 123），每行一名受试者。主要终点缺失者不进入主要分析。
- **比较对象或主要解释变量**：`disease`，二分类（1 表示 `num > 0`，即存在冠心病证据；0 表示 `num = 0`）。
- **主要终点及单位**：`thalach`，运动试验达到的最大心率，单位 bpm，连续变量。
- **测量时间或观察窗口**：横断面，单次运动试验中的峰值测量，无随访。
- **分析单位**：每名受试者 1 行、1 次观察，无重复测量，因此两组是**独立样本**而非配对样本。
- **研究设计**：观察性、横断面、独立两组比较；无随机分组，无干预。
- **计划使用的数据来源**：课堂数据 `heart-disease-hypothesis.csv`（源自四中心心脏病数据，保留假设检验所需字段）。不另寻外部数据。未来若要支持更强结论，需前瞻性队列（见第七节）。

## 二、统计假设

- **待检验的参数及其定义**：两组总体均数之差 Δ = μ₁（disease=1）− μ₀（disease=0），单位 bpm。
- **H0**：Δ = 0，即患病组与未患病组的最大心率总体均值相同。
- **H1**：Δ ≠ 0，即两组总体均值不同。
- **显著性水平 α**：0.05（双侧）。
- **双侧或单侧及理由**：**双侧**。虽然临床常识倾向于患病者运动耐量更低、最大心率更低，但本数据是观察性数据，最大心率还受用药（如 β 受体阻滞剂会压低心率）、运动方案、用力程度与中心差异影响，方向并非必然；本研究定位为描述关联而非验证预先设定的方向性假说，双侧更保守，也不会因为结果与预期方向相反就无法解释。
- **哪些选择需要在查看结果前确定**：唯一主要终点（仅 `thalach`）、α = 0.05、双侧、首选方法（Welch 两样本 t 检验）、协变量集合（`age`、`sex`、`site`）、缺失处理（完整病例为主分析）、主要分析与探索性分析的边界。以上均在分析前锁定，不因结果调整。

## 四、统计方法与依据

- **首选统计方法**：Welch 两样本 t 检验（不等方差 t 检验），比较两组 `thalach` 的均值差。
- **为什么适合本研究设计和变量类型**：结局是连续变量，两组相互独立（一人一行、无重复测量），研究关心的是"均值差"这一有单位的效应量；Welch 版不需要方差齐性假设，在每组样本量数百时对轻度偏态也较稳健，比 Student t 检验更保守。
- **关键假设与检查方式**：
  1. **独立性**——由设计保证：每名受试者只出现一次，无配对、无重复测量。
  2. **近似正态或大样本**——画两组 `thalach` 的直方图与 Q-Q 图观察偏态；两组有效 n 分别为 474 与 391，中心极限定理下均值差的抽样分布近似正态，即使原始分布偏态也基本可用。
  3. **方差齐性**——做 Levene 检验；若方差不齐，Welch 版本本身已不依赖该假设。
  4. **取值合理性与录入错误**——检查 `thalach` 是否落在生理范围（约 60–220 bpm），排除录入异常与不可能值。
- **至少一种备选方法及其适用条件**：**Mann-Whitney U 检验（Wilcoxon 秩和）**，适用于分布明显偏态、存在极端值，或关注点从"均值"转为"分布位置"的情形。**若更换方法，解释对象会改变**：t 检验回答"两组均值相差多少 bpm"；Mann-Whitney 回答"随机取一名患病者与一名未患病者，前者最大心率低于后者的概率"（随机优势），效应量应改用 Hodges-Lehmann 位置平移估计，而不是均值差。
- **若需控制混杂**：多重线性回归 `thalach ~ disease + age + sex + site`，报告 `disease` 的回归系数，即调整后均值差及其 95% 置信区间。该模型假设残差近似正态、方差齐、自变量间不存在严重共线性（用 VIF 检查）。敏感性分析中再逐个加入 `trestbps`、`chol` 观察系数是否稳定。

## 五、混杂、缺失与多重比较

| 潜在混杂因素 | 为什么可能影响本题关联 | 控制或敏感性分析计划 |
|---|---|---|
| **年龄 `age`** | 最大心率随年龄明显下降（临床常用 220 − 年龄 估计），同时年龄越大冠心病患病风险越高；不调整会把年龄效应错误地记到"疾病"上 | 主模型调整 `age`（连续）；敏感性分析按 < 55 岁 / ≥ 55 岁分层重跑，看方向与量级是否一致 |
| **性别 `sex`** | 男女的最大心率与冠心病患病率都不同（本数据女 194、男 726），性别构成不平衡会混入比较 | 主模型调整 `sex`；敏感性分析只在男性子集中重跑 |
| **中心 `site`** | 四个中心的运动方案、设备与受试者来源不同，`thalach` 的测量口径可能不同；同时中心与疾病状态高度相关（例如 Switzerland 中心 123 人中仅 8 例未患病），不调整会让中心构成差异与疾病效应混在一起 | 主模型把 `site` 作为分类协变量（固定效应，以 Cleveland 为参照）；敏感性分析逐中心单独估计 |
| **运动后 ST 压低 `oldpeak`** | 它是运动试验的**结果**，与最大心率处在同一过程的下游；把它当协变量属于"过度调整"，可能屏蔽掉真实关联 | **不进入主模型**；只作探索性描述，并说明不作调整的理由 |

- **哪些因素尚未测量、只能列为限制**：影响心率的用药（β 受体阻滞剂、钙通道阻滞剂等）、具体运动方案（Bruce 等）与终止标准、受试者的体能水平与合并症（糖尿病、慢阻肺）、测量批次与操作者、招募与转诊方式。这些在本数据里都没有字段，**不能在文中声称已控制**，只能写进结论边界。
- **缺失值如何检查与处理**：主要终点 `thalach` 缺失 55/920（6.0%），两组分别为 35/509 与 20/411；`trestbps` 缺失 59、`chol` 缺失 30、`oldpeak` 缺失 62。先比较缺失者与非缺失者在 `age`、`sex`、`disease` 上的分布，判断缺失是否与疾病状态相关——若相关，完整病例分析会带来选择偏倚。主分析采用**完整病例**（complete case）并明确报告各组有效 n；敏感性分析用**多重插补**（MICE，假定随机缺失 MAR）重跑，比较两套结果是否一致。若两者结论不同，则以"结果对缺失处理敏感"作为报告结论，不挑有利的一套。
- **预先指定的主要终点**：仅 `thalach` 与 `disease` 的关联，其余一律不是主要终点。
- **是否还有其他指标、亚组或时间点**：有。`trestbps`、`chol`、`oldpeak`、`age`、`sex` 与 `disease` 的关系，以及按年龄、性别、中心划分的亚组，全部标为**探索性**；本数据只有一个时间点，无重复测量。
- **多重比较控制及探索性结果的报告计划**：主要终点单一，不做校正。探索性部分若凑成 20 个指标的筛查，α = 0.05 下期望假阳性为 20 × 0.05 = 1 个，因此同时报告 Bonferroni 阈值 0.05/20 = 0.0025 与 BH-FDR 校正结果。**不允许在看过结果后把某个显著的探索性指标改称为"主要终点"**，也不允许只挑显著的结果报告。

## 六、错误类型、power 与结果报告计划

- **本研究中的 Type I error**：两组真实均值相同，却因为抽样波动被判为"有差异"并拒绝 H0。这是本研究固定为 α = 0.05 的那类错误，意味着即使完全无效，约 20 次同样的研究也会有 1 次得到"显著"。
- **本研究中的 Type II error**：两组真实存在差异（例如真实均值差 5 bpm），却因为样本量不足或测量噪声大而未能检出，从而不拒绝 H0。对应用 power = 1 − β。
- **样本量、真实效应、测量噪声如何影响 power**：样本量增大 → 均值差的标准误变小 → power 升高；真实效应（Δ）增大 → 更容易从噪声中分离 → power 升高；测量噪声（组内标准差）增大 → 标准误变大 → power 降低。本数据 `thalach` 的总体 SD 约 25.9 bpm，是一个不小的噪声水平，因此小到 2–3 bpm 的真实差异在没有极大样本时几乎不可能检出。
- **样本量或 power 如何考虑（定性说明，不做事后 power）**：`thalach` 有效样本为 disease=1 组 474 人、disease=0 组 391 人。在 α = 0.05 双侧、power = 0.80 的条件下，两组不等样本量可检出的效应量约为 Cohen's d = 0.19；若组内 SD 取 25.9 bpm，对应可检出的均值差约 **5.0 bpm**。这是分析**前**的计划性估算，用于说明"小于约 5 bpm 的差异即使真实存在，本研究也可能检不出"，不是研究结果，也不做事后 power 计算。
- **各组有效样本量和描述统计将如何报告**：明确报告剔除缺失后的各组有效 n（预计 disease=1 为 474、disease=0 为 391，以实际剔除结果为准），并给出各自的均值 ± 标准差、中位数（IQR）与取值范围，同时报告缺失人数与比例。
- **计划报告哪一种效应量，如何定义方向与单位**：报告均值差 Δ = 患病组均值 − 未患病组均值，单位 bpm，负值表示患病组心率更低；同时报告其 95% 置信区间，并附 Cohen's d 以便与文献比较。效应量的方向与单位在报告中必须写清，不只给 p 值。
- **95% 置信区间和 p 值将如何报告和解释**：两者并列报告。p 值只用于对照 α 做"拒绝/不拒绝 H0"的二元决策，不解读为"效应大小的度量"，也不表述为"p 越小差异越重要"。95% CI 用于表达估计的不确定性，并直接说明"数据与多大的差异相容、与多大的差异不相容"。
- **未拒绝 H0 时，为什么不能直接说"证明没有效应"**：不拒绝 H0 只说明在当前样本量与测量噪声下，没有观察到足以排除随机波动的证据。原因可能是真的没有差异，也可能是真实效应小于本研究的可检出下限（约 5 bpm），或组内噪声过大。正确表述是"未发现可检出的差异（均值差 X bpm，95% CI [a, b]）"，并说明该 CI 是否已排除具有实际意义的差值。

## 七、结论表达与边界

以下用条件句表达计划，不预设研究一定显著。

- **主张**：如果调整年龄、性别与中心之后，患病组与未患病组的最大运动心率仍存在方向一致、置信区间不含 0 的差异，那么可以表述为"在四个中心接受运动试验的人群中，冠心病证据与运动能达到的最大心率存在关联"；**但不能表述为"患病导致最大心率下降"**。
- **证据**：Welch 两样本 t 检验得到的均值差及其 95% CI；以及 `thalach ~ disease + age + sex + site` 回归中 `disease` 的调整后系数及其 95% CI。同时报告各组有效 n、缺失情况与缺失敏感性分析结果。
- **推理**：若差异在未调整与调整后都存在，说明它不是单纯由年龄、性别或中心构成差异解释的；但本数据中"疾病状态"与"最大心率"是同一时点测量的，无法确定先后，也无法排除未测量的因素（用药、体能、运动方案）同时影响两者。
- **边界**：观察性、横断面、四中心、单次测量；`thalach` 是运动试验的峰值，受主观用力程度、用药与运动方案影响；无随机分组、无随访；主要终点缺失 6.0%；β 受体阻滞剂等关键用药未测量；能完成运动试验者本身是经过筛选的人群。因此结论只能支持"存在关联"，不能支持因果、不能外推到其他人群、不能用于临床决策。
- **如何区分统计显著与生物学/临床重要性**：α = 0.05 只说明数据与 H0 不相容，样本足够大时 2 bpm 的差异也可能"显著"。是否重要取决于效应量的绝对值与 CI 是否跨过临床最小重要差异（MCID）。本研究不预设 MCID，但报告时必须给出绝对差值（bpm）及其 CI，让临床判断有的放矢；若 CI 覆盖了常识上无意义的范围（如 ±1 bpm），则应说明"统计学上可区分、临床上不可区分"。
- **研究设计是否支持因果推断，为什么**：**不支持**。没有随机化，无法平衡未测量混杂；没有时间先后，无法确立"疾病 → 心率"的方向（甚至可能是体能水平同时影响两者）；还存在选择偏倚（转诊与能否完成运动试验）。
- **若要支持更强的结论，还需要什么证据**：前瞻性队列（先测最大心率，再随访冠心病发病）、统一记录并调整运动方案与心血管用药、多中心统一测量协议、在外部独立队列中复现同一关联；若要谈干预，则需要随机对照设计，而把最大心率当作干预目标本身缺乏临床依据。
