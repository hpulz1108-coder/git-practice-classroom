## 一、科学问题与研究设计

- **科学问题：**在课程提供的四中心心脏病数据中，有心脏病证据者与无心脏病证据者的最大运动心率平均值是否不同？
- **研究对象与范围：**课堂数据中的受试者；主要分析纳入 `disease` 与 `thalach` 均有记录者，并报告排除人数。该数据来自四个中心，不代表随机抽取的全部人群。
- **比较对象：**`disease=1`（原始 `num>0`）与 `disease=0`（原始 `num=0`）。
- **主要终点：**`thalach`，最大运动心率，单位为次/分钟。
- **测量时间或观察窗口：**数据记录的一次检查；没有纵向时间或重复测量信息。
- **分析单位：**每名受试者一行；`record_id` 仅用于识别记录。
- **研究设计：**观察性横断面研究中的独立两组比较。两组不是随机分配的治疗组，也不是同一患者前后配对。
- **数据来源：**`resources/data/heart-disease-hypothesis.csv`。课程说明指出该数据用于统计推断练习，不能直接支持治疗效果或因果结论。

## 二、统计假设

- **待检验的参数：**`Δ = μ(disease=1) − μ(disease=0)`，即两种疾病状态受试者最大运动心率总体均值之差，单位次/分钟。
- **H0：**`Δ = 0`，两组总体均值相同。
- **H1：**`Δ ≠ 0`，两组总体均值不同。
- **显著性水平：**双侧 `α=0.05`。
- **双侧或单侧及理由：**双侧。研究问题问的是“是否不同”，现有资料没有足够依据在看结果前限定方向。
- **需在查看结果前确定：**主要终点、疾病分组编码、双侧检验、α、主要方法和缺失值规则均在查看检验结果前确定，不依据观察方向改成单侧检验。

## 三、变量类型

| 变量 | 在研究中的作用 | 类型与单位/编码 |
|---|---|---|
| `thalach` | 主要结局 | 连续，次/分钟 |
| `disease` | 主要解释变量 | 二分类，0=`num=0`，1=`num>0` |
| `age` | 调整分析协变量 | 连续，岁 |
| `sex` | 调整分析协变量 | 二分类，0=female，1=male |
| `site` | 调整分析协变量 | 四类别名义变量，来源中心 |

## 四、统计方法与依据

- **首选统计方法：**双侧 Welch 独立样本 t 检验，估计并报告 `disease=1` 减去 `disease=0` 的均值差及 95% 置信区间。
- **为什么适合：**结局 `thalach` 是连续变量，比较对象是两个互不重叠的受试者组，目标参数是均值差；Welch 版本不要求两组方差相等，比合并方差 t 检验更适合本数据中没有理由假定方差相等的情形。
- **关键假设与检查方式：**
  - 观测相互独立：一名受试者一行，核对 `record_id` 是否有重复、是否存在同一患者多次入组；
  - 分布近似正态，或样本量足够大使均值抽样分布近似正态（中心极限定理）：用直方图、QQ 图及偏度、峰度检查各组 `thalach`；偏态明显时同时报告中位数和四分位距；
  - 方差不齐不影响 Welch 的推断，但仍报告两组标准差；
  - 极端值：核对异常值是录入问题还是真实值，不为追求结果而删点；若删除或调整，须预先写明规则并做敏感性分析；
  - 中心结构：若中心内观测相关，普通检验的标准误可能偏小；因此另做纳入中心的调整分析，并可将中心设为随机效应或使用聚类稳健标准误。
- **备选方法及其适用条件：**若均值比较受严重偏态或极端值影响，可考虑受试者层面的置换检验及自助法区间，但置换需要零假设下标签可交换，中心结构可能使此条件不成立。Mann–Whitney U 检验可用于排序/分布位置差异的补充分析，但一般不等同于均值差检验；采用时须说明研究问题对象改变。
- **调整敏感性分析：**线性回归以 `thalach` 为结局，纳入 `disease`、`age`、`sex`、`site`，报告疾病状态系数及 95% 区间。检查残差、非线性和影响点。该分析用于评估关联对可测协变量调整的稳健性，不能消除未测量混杂，也不替代主要检验。

## 五、混杂、缺失与多重比较

| 潜在混杂因素 | 为什么可能影响本题关联 | 控制或敏感性分析计划 |
|---|---|---|
| 年龄 `age` | 年龄可能与疾病证据和可达到的最大心率均有关。 | 调整分析纳入年龄连续项；查看非线性，若有依据再采用适当形式并报告。 |
| 性别 `sex` | 两组性别构成可能不同，且性别可能关联最大心率。 | 调整分析纳入性别分类项，并报告组间构成。 |
| 中心 `site` | 中心间病例构成或测量流程可能不同，合并比较会受中心比例影响。 | 调整分析纳入中心固定效应；检查各中心疾病组构成及方向，不将中心当成随机治疗组。 |

- **尚未测量、只能列为限制的因素：**用药（包括影响心率的药物）、体能/运动习惯、吸烟及更完整的病史可能同时关联疾病证据和最大心率；现有 CSV 不足以控制这些因素，因此不能声称已控制。
- **缺失值检查与处理：**统计各变量缺失数和比例，空值不当作 0。主要检验使用 `disease` 和 `thalach` 完整的记录，报告两组有效 `n` 及因缺失排除人数。调整分析另报协变量完整记录数，并比较纳入与未纳入者的可观察特征，以判断完整案例分析的选择偏差风险。若缺失较多或呈系统差异，结果可能有偏；只有在明确缺失机制假设后才考虑多重插补敏感性分析。
- **预先指定的主要终点：**`thalach`。
- **其他指标、亚组或时间点：**不设为确证性分析；如开展，标注为探索性并完整披露。
- **多重比较：**主要检验只做一次。若开展多个探索性检验，说明检验数量，并对这组探索性检验采用 Benjamini–Hochberg 方法控制错误发现率，同时报告未校正结果并强调探索性质。不选择性报告显著指标或亚组。

## 六、错误类型、power 与结果报告计划

- **本研究中的 Type I error：**两组总体平均最大运动心率实际相同，却因抽样波动得到 `p<0.05`，错误地声称存在差异。
- **本研究中的 Type II error：**两组总体均值实际有差异，却因样本量不足、差异较小或测量变异较大而未能拒绝 H0。
- **样本量、真实效应、测量噪声如何影响 power：**其他条件相同时，样本量增加通常提高对给定差异的检出能力；真实差异越大越容易检出；测量误差、个体差异及组内变异越大，power 越低。组间人数不平衡时，小组通常限制精度。
- **样本量或 power 如何考虑：**本作业是课堂数据上的设计练习，不做事后 power 计算。前瞻性研究应根据有依据的最小重要均值差、合理组内标准差、双侧 α=0.05、目标 power（如 80% 或 90%）、组间比例和预期缺失率，在收集前估算样本量并记录假设；依据不足时做范围情景分析，不给虚假精确值。
- **各组有效样本量和描述统计：**报告每组有效 `n`、均值、标准差；对偏态或异常值同时报告中位数和四分位距，并报告因结局缺失排除数及调整模型的有效样本量。
- **效应量及其方向与单位：**主要效应量为未调整均值差 `平均(thalach | disease=1) − 平均(thalach | disease=0)`，单位次/分钟，正值表示疾病证据组平均较高，负值表示较低；可另报标准化均值差（Cohen's d）作为跨研究的可比补充，但不作为主要终点。调整模型系数另行报告，不与未调整差值混为一谈。
- **95% 置信区间和 p 值：**报告均值差的 95% 置信区间及双侧 p 值，给出适当精度，不写 `p=0.000`。区间是在模型和抽样假设下与数据相容的效应范围；p 值不是 H0 为真的概率，也不衡量临床重要性。
- **未拒绝 H0 时：**只表示证据不足以在设定的 α 下排除零差异，不等于证明两组相同。应结合效应估计、区间宽度和有实际意义的差异，判断结果仍容许哪些可能性。

## 七、结论表达与边界

本文尚未报告检验结果，结论按下列条件表达，不预设显著。

- **主张：**如果预设的双侧检验拒绝 H0，则称“在这份课堂横断面样本中，两种疾病状态受试者的最大运动心率均值存在统计学差异”；若未拒绝，则称“本分析没有足够证据拒绝两组均值相同的假设”。
- **证据：**两组有效样本量、描述统计、未调整均值差、95% 置信区间和 Welch 检验 p 值；调整分析作为敏感性结果单独呈现。
- **推理：**若 p 值低于预设 α，数据与零均值差假设不太相容；差异方向与可能大小依据估计值和区间判断。若区间仍容许有实际意义的差异，不能仅因未显著就断言没有重要差异。
- **边界：**统计显著不代表差异有临床/生物学意义；需结合事先有依据的阈值、效应大小和区间判断。疾病状态非随机分配，横断面数据时间顺序不清，且可能有选择偏差及未测量混杂，故不能说疾病导致心率变化，也不能直接推广到其他人群。
- **如何区分统计显著与生物学/临床重要性：**显著性受样本量影响，表达数据与零差异假设的相容程度；实际重要性取决于效应量、区间及事先认可的临床/生物学阈值。报告时同时呈现，不用 `p<0.05` 代替重要性判断。
- **研究设计是否支持因果推断：**不支持。观察性横断面设计没有随机分配，也没有明确的时间先后，混杂无法被现有字段完全控制。
- **若要支持更强的结论，还需要什么证据：**需要明确时间顺序的纵向研究、较完整测量并控制混杂因素；治疗效果问题需伦理可行且设计严谨的随机对照研究，或具备充分因果识别假设的其他设计，并在独立人群复现。
