## 一、科学问题与研究设计

- 用一句话写出科学问题：在本数据集中，有心脏病证据的受试者与无心脏病证据的受试者，其最大运动心率平均值是否不同？
- 研究对象与纳入范围：CSV 中来自 Cleveland、Hungary、Switzerland、VA Long Beach 四个中心的受试者。主要比较纳入 `disease` 和 `thalach` 均非缺失者；这是数据集中的观察样本，不代表一般人群的随机样本。
- 比较对象或主要解释变量：`disease=1`（原始 `num>0`，有心脏病证据）与 `disease=0`（`num=0`，无心脏病证据）。
- 主要终点及单位：最大运动心率 `thalach`，次/分钟（bpm）。
- 测量时间或观察窗口：数据记录的单次检查/观察值；文件没有提供重复测量时间信息。
- 分析单位：一名受试者一行。
- 研究设计（观察性/实验性，独立组/配对等）：观察性、横断面式的两独立组比较；不是随机分配，且没有同一受试者前后测量。
- 计划使用的数据来源；没有数据时说明未来如何收集：`heart-disease-hypothesis.csv`，字段编码依据同目录 `README.md`。四个中心视为来源中心，不当作随机处理组。

## 二、统计假设

- 待检验的参数及其定义：Δ = μ₁ − μ₀；μ₁ 是数据所代表目标中 `disease=1` 受试者的平均 `thalach`，μ₀ 是 `disease=0` 受试者的平均 `thalach`。
- H0：Δ = 0，两组总体平均最大运动心率相同。
- H1：Δ ≠ 0，两组总体平均最大运动心率不同。
- 显著性水平 α：0.05。
- 双侧或单侧及理由：双侧。问题只问是否“有关/不同”，没有在看结果前充分指定方向；双侧检验也允许发现任一方向的差异。
- 哪些选择需要在查看结果前确定：主要终点 `thalach`、疾病分组定义、纳入/排除规则及缺失处理、双侧方向、α、首选检验、效应量和置信区间，以及多重比较策略。不得因结果显著与否临时更换这些选择。

## 四、统计方法与依据

- 首选统计方法：Welch 两独立样本 t 检验，检验两组均值差；同时报告组别均值、样本标准差、均值差、95% Welch 置信区间和 p 值。效应量报告未标准化均值差（疾病组减无疾病组，单位 bpm），并可附 Cohen's d 作标准化补充。
- 为什么适合本研究设计和变量类型：每人只进入一个疾病组，`thalach` 为定量变量；Welch 检验比较独立组均值且不要求两组方差相等。它回答本设计预先指定的均值差问题。
- 关键假设与检查方式：受试者观测相互独立；组内分布没有严重到破坏均值推断的异常偏态或极端值；抽样/数据记录能支持所用推断。通过按组绘图、检查异常值和分布，并核对重复记录；Welch 方法不要求方差齐性。四中心来源及病例构成可能破坏简单同质性，因此另按中心分层描述或作含中心、年龄、性别的调整敏感性分析，不能把中心视为随机处理组。
- 至少一种备选方法及其适用条件；若更换方法，解释对象是否改变：若分布明显偏斜或极端值使均值推断不稳，可用置换检验/稳健 bootstrap 估计均值差，目标仍为均值差；也可用 Mann–Whitney U 检验比较秩/分布位置，但其一般不等于检验均值差，解释对象会改变。工作单其余问题的计划方法：① 疾病组与无疾病组 `thalach`：Welch t 检验；假设独立、均值推断稳定；备选 Mann–Whitney U（解释为秩分布差异）。② 同一患者前后测量：配对 t 检验；假设配对差值近似正态且配对正确；备选 Wilcoxon 符号秩检验。当前 CSV 不含前后配对数据，不能执行。③ `sex` 与 `disease` 比例：卡方独立性检验；假设个体独立且期望频数足够；备选 Fisher 精确检验。④ `age` 与 `thalach` 相关：Pearson 相关；假设关系近似线性、无强影响点；备选 Spearman 秩相关（单调关系）。⑤ `age`、`sex`、`thalach` 预测二元 `disease`：多变量 logistic 回归；假设观测独立、连续预测变量与 log-odds 关系适当且无严重共线性；备选带惩罚项的 logistic 回归（如小样本/分离时）。预测关联不代表因果。

## 五、混杂、缺失与多重比较

|---|---|---|
| 年龄（`age`） | 年龄可能与最大运动心率相关，也可能与疾病证据相关 | 按年龄描述两组；拟合含年龄的调整模型或年龄分层敏感性分析，并与未调整均值差并列，不把调整结果直接解释为因果效应 |
| 性别（`sex`） | 性别构成可能在疾病组间不均衡，且可能关联心率水平 | 报告性别构成；在调整模型中纳入性别，必要时检查分层结果 |
| 来源中心（`site`） | 各中心受试者来源、病例比例、记录和测量流程可能不同 | 报告中心与疾病组构成；按中心分层描述或纳入固定效应作敏感性分析；中心不是随机处理组 |

- 缺失值如何检查与处理，处理可能带来什么影响：分析前按变量和疾病组汇总缺失数及模式。本次 `thalach` 完整案例分析：全表 920 行，`thalach` 缺失 55 行，纳入 865 行；不对缺失心率作均值填补。若缺失与疾病严重程度或其他因素有关，完整案例结果可能有选择偏倚；应报告缺失者与非缺失者可观察特征，并在后续分析考虑合理的多重插补/敏感性分析。数据定义中的空值保持为空，不擅自把其他数值改作缺失。
- 预先指定的主要终点：`thalach`。
- 是否还有其他指标、亚组或时间点：数据还含 `age`、`sex`、`trestbps`、`chol`、`oldpeak` 等；按中心或性别分层仅作为敏感性/探索性分析，不替代主要终点。当前主要结论只针对 `thalach`。
- 多重比较控制及探索性结果的报告计划：若对约 20 个指标分别检验，会增加至少一次假阳性的概率；不能只挑显著项汇报。主要分析只检验预先指定的 `thalach`；其他指标明确标记探索性，完整报告检验数量、效应和区间，并采用 Holm 校正（或预先说明的 FDR 方法）控制多重比较。

## 六、错误类型、power 与结果报告计划

- 本研究中的 Type I error：实际上两组平均 `thalach` 相同，却因随机波动得到 p<0.05 并错误地宣称有关联。
- 本研究中的 Type II error：两组实际平均 `thalach` 不同，却因样本量不足、效应较小或数据噪声较大而未拒绝 H0。
- 样本量、真实效应、测量噪声如何影响 power：样本量增加通常降低标准误、提高发现既定效应的概率；真实差异越大越容易检出；心率测量误差、个体差异和异质性增大方差，通常降低 power。
- 样本量或 power 如何考虑（可定性说明，无需计算事后 power）：后续前瞻性研究应依据预先定义的最小有意义差异、合理的组内变异估计、双侧 α=0.05 和目标 power（如 80% 或 90%）估算样本量，并考虑缺失、中心差异及组间不平衡。不以观察到的 p 值倒推“事后 power”。
- 各组有效样本量和描述统计将如何报告：本次有效样本为 disease=0：n=391，均值 148.80、SD 23.61、median 151 次/分钟；disease=1：n=474，均值 128.26、SD 24.02、median 128 次/分钟。另说明 55 个 `thalach` 缺失未纳入。
- 计划报告哪一种效应量，如何定义方向与单位：报告均值差 Δ=疾病组均值−无疾病组均值，单位 bpm；负值表示疾病组均值较低。Cohen's d 作为补充标准化效应量，约为 -0.86（以两组 pooled SD 标准化）。
- 95% 置信区间和 p 值将如何报告和解释：观察到 Δ=-20.54 bpm；Welch 95% CI [-23.73, -17.35] bpm；双侧 p=1.30×10⁻³³（报告为 p<0.001 亦可）。在检验假设与抽样推断成立的前提下，区间表示与数据相容的均值差范围；p 值不是 H0 为真的概率，也不衡量临床重要性。
- 未拒绝 H0 时，为什么不能直接说“证明没有效应”：不显著可能来自真实差异很小，也可能来自样本量不足、测量噪声或缺失造成的低 power；应结合效应估计和置信区间判断数据排除了哪些差异，而不是把未拒绝当作相等证明。

**实际主要结果与决策：** Welch 检验 t=-12.63，df≈837.18，p=1.30×10⁻³³。因 p<0.05，拒绝 H0。结果显示本样本中心中 `disease=1` 组最大运动心率平均低于 `disease=0` 组约 20.54 bpm，差值的 95% CI 为 [-23.73, -17.35] bpm。统计关联证据强；这本身不说明差异具有临床重要性，需结合临床阈值、患者结局和专业判断；也不构成疾病导致心率降低的因果证据。

## 七、结论表达与边界

- 主张：在该多中心观察数据的有效完整案例中，有心脏病证据者的 `thalach` 平均值低于无疾病证据者。
- 证据：无疾病组 n=391，均值 148.80 bpm（SD=23.61）；疾病组 n=474，均值 128.26 bpm（SD=24.02）；均值差（疾病组−无疾病组）=-20.54 bpm，95% CI [-23.73, -17.35]，Welch 双侧 p<0.001。
- 推理：在预设 α=0.05 下拒绝两组均值相同的 H0；置信区间整体低于 0，支持本样本中疾病组均值较低的统计关联。
- 边界：这是按 `num>0` 派生疾病标签的观察性、完整案例比较；四中心样本不是随机分配，中心间构成不同，且可能存在残余混杂、选择偏差及缺失偏差。不能推断因果，也不应无条件外推到一般人群或作临床决策。
- 如何区分统计显著与生物学/临床重要性：p 值反映数据与零差异假设的相容程度；均值差约 20.54 bpm 是量级信息，但是否具有临床意义须结合预先定义的临床阈值、临床背景和结局验证，不能由 p<0.05 单独决定。
- 研究设计是否支持因果推断，为什么：不支持。疾病不是随机分配的，时间顺序与混杂控制不足；观察到的差异可能来自年龄、性别、中心、用药、体能或其他因素。
- 若要支持更强的结论，还需要什么证据：更具代表性的前瞻性多中心队列，统一测量流程、明确时间顺序、充分测量并调整重要混杂因素、妥善处理缺失并进行外部验证；若研究某种干预对心率的因果作用，则需适当设计的随机对照研究。

可复核 Python 代码（需安装 pandas、scipy）：

```python
import pandas as pd
from scipy import stats

path = "heart-disease-hypothesis.csv"
df = pd.read_csv(path)
valid = df.dropna(subset=["thalach", "disease"])
groups = {
    int(label): part["thalach"].to_numpy()
    for label, part in valid.groupby("disease")
}
no_disease = groups[0]
disease = groups[1]
test = stats.ttest_ind(disease, no_disease, equal_var=False)
delta = disease.mean() - no_disease.mean()
se = ((disease.var(ddof=1) / len(disease)) +
      (no_disease.var(ddof=1) / len(no_disease))) ** 0.5
df_welch = test.df
ci = stats.t.interval(0.95, df_welch, loc=delta, scale=se)

print(valid.groupby("disease")["thalach"].agg(["count", "mean", "std", "median"]))
print("difference (disease - no disease):", delta)
print("95% CI:", ci)
print("Welch t, df, p:", test.statistic, test.df, test.pvalue)
```
