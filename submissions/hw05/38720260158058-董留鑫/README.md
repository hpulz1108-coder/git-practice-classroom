## 一、科学问题与研究设计

**科学问题：**在四中心心脏病课堂数据的受试者中，年龄与最大运动心率是否存在线性关联？

- 数据来源：课程提供的 `assignments/hw05/resources/data/heart-disease-hypothesis.csv`。
- 研究对象：数据中来自四个中心的受试者。主要分析纳入年龄和最大运动心率均有记录的人，并报告排除人数。
- 主要解释变量：年龄 `age`，单位为岁；不人为划分年龄组，保留其连续信息。
- 主要终点：一次运动测试中的最大心率 `thalach`，单位为次/分钟。
- 测量时间和分析单位：使用数据中记录的该次检查；每行是一名受试者，以人为单位分析。
- 研究设计：观察性横断面研究，不是随机试验，也不是同一人前后配对比较。来源中心不代表随机处理组。

课堂工作单比较有无疾病证据两组的心率；本设计书研究连续年龄与心率的关系，主要参数和检验均不同。

## 二、统计假设

令 β 为目标人群中未调整线性回归的年龄斜率。在模型适用时，它表示年龄每增加一岁时，最大运动心率条件均值的平均差异，单位为次/分钟/岁；不是同一个人随年龄增长的实测变化。

- H0：β = 0，即年龄的总体线性回归斜率为零。
- H1：β ≠ 0，即年龄的总体线性回归斜率不为零。
- 显著性水平 α = 0.05，采用双侧检验，因为不预先排除任一方向。
- 查看结果前确定人群、主要终点、效应量及方向、模型、检验方向、α 和缺失值处理。

## 三、变量类型

| 变量 | 角色 | 类型和编码 |
|---|---|---|
| `thalach` | 结局 | 连续，次/分钟 |
| `age` | 主要解释变量 | 连续，岁 |
| `sex` | 调整模型协变量 | 分类，0=female、1=male |
| `site` | 调整模型协变量 | 分类，来源中心 |
| `disease` | 敏感性分析协变量 | 二分类，0=无疾病证据、1=有疾病证据 |

## 四、统计方法与依据

**方法选择流程：**先明确研究问题和主要结局，再按以下顺序选择方法：

1. 结局变量是分类变量还是连续变量？
2. 分类结局若比较比例或分类变量关联，选择卡方；期望频数较小时选择 Fisher；若要调整协变量或预测二分类结局，选择 logistic 回归。
3. 连续结局若比较组间差异，先判断是独立组还是同一人的配对数据：独立组优先考虑 Welch t，配对数据优先考虑配对 t。
4. 如果均值模型不适合，再根据研究目标考虑 Mann–Whitney U 或 Wilcoxon；此时检验对象可能从均值差变为秩或分布位置差异。
5. 连续变量若研究关联，线性关系优先考虑 Pearson 相关或线性回归；单调但非线性或异常值影响明显时考虑 Spearman 相关。
6. 最后检查独立性、分布或残差、异常值、方差、样本量、缺失值、混杂和多重比较。

本设计书沿着该流程选择方法：thalach 是连续结局，age 是连续解释变量，研究目标是变量间关联而不是组间均值比较，因此首选线性回归；未经调整的线性关联可用 Pearson 相关作为补充。

**首选方法：**普通最小二乘线性回归，以 `thalach` 为结局、`age` 为解释变量，对年龄斜率进行双侧检验。两个变量都是连续变量，回归斜率能用原始单位表达年龄与平均心率的线性关系。

**关键假设和检查：**检查数据范围、年龄与心率散点图，判断线性关系是否合理；检查残差与拟合值图，查看非线性、方差变化和异常值；用残差图或 Q-Q 图检查误差分布。常规推断要求观测独立、残差等方差；小样本下还要求误差近似正态。还需按中心查看数据分布，考虑同一中心受试者可能存在相似性。

**备选和敏感性分析：**若明显异方差，可补充异方差稳健标准误；若明显非线性，可探索非线性模型，此时单一线性斜率不能完整描述关系。若异常值或非正态严重且关注单调关系，可辅以 Spearman 秩相关：它衡量秩的单调关联，不再估计每增加一岁对应的平均心率差。中心内观测可能相关，可探索按中心聚类的稳健标准误，但只有四个中心时这种估计可能不可靠，应谨慎解释，不视为已解决中心相关问题。

## 五、混杂、缺失与多重比较

| 潜在混杂因素 | 可能影响 | 控制或敏感性分析 |
|---|---|---|
| 性别 | 不同性别的年龄分布与运动心率可能不同 | 多变量回归调整性别，比较调整前后斜率 |
| 中心 | 年龄构成和测试方式可能因中心不同 | 以中心为分类协变量调整，检查各中心散点 |
| 疾病状态 | 可能与年龄及运动能力有关 | 补充调整疾病状态的模型；如果疾病处于年龄影响心率的路径上，调整会改变估计目标 |

体能、用药和测试方案等可能影响心率，但本章字段未提供，不能声称已控制。受试者选择及残余混杂也是限制；调整后的结果仍不能自动解释为因果效应。

先汇总各变量、疾病状态及中心的缺失数与比例，检查缺失模式。主要分析采用年龄和 `thalach` 完整的记录；调整模型还需协变量完整，报告各模型有效样本数并比较纳入与排除者。缺失未必随机，完整案例分析可能有选择偏倚；若缺失较多且条件允许，可在说明缺失机制假设后探索多重插补，并与完整案例结果比较。

预先指定 `thalach` 为唯一主要终点，年龄斜率为唯一主要检验。调整模型、非线性和中心分析为敏感性或探索性分析，完整报告预定结果，不只挑显著结果。若未来设置多个正式验证性假设，应事先规定检验族及校正方法，例如 Holm 法。

## 六、错误类型、power 与报告计划

- Type I error（假阳性）：目标人群的真实年龄斜率为零，却错误地认为年龄与最大运动心率存在线性关联。
- Type II error（假阴性）：目标人群的真实年龄斜率不为零，却未能拒绝零斜率假设。
- 其他条件相同时，更大有效样本量和更大真实效应通常提高 power；更大的测量噪声通常降低 power。年龄分布、缺失和中心内相关也影响有效信息量。
- 使用现有数据时报告可用样本及限制；若设计新研究，应事先根据有意义的斜率、残差变异、α 和目标 power 估算样本量，并考虑缺失和中心聚集。不计算事后 power。
- 本研究不按年龄人为分组，故没有主要比较组；报告总体及各中心记录数、分析有效样本数和缺失数，描述年龄与心率均值和标准差，明显偏态时补充中位数及四分位数。疾病组描述不作为主要分组检验。
- 报告斜率 β、95% 置信区间和双侧 p 值；正斜率表示年龄增加时心率均值升高。区间反映与模型和数据相容的效应范围；p 值是零假设及模型假设成立时观察到同等或更极端结果的概率，不是零假设为真的概率。
- 按预设 α 决定是否拒绝 H0，并结合区间判断可能的实际意义。未拒绝可能是效应小、样本不足或噪声大，不能证明没有效应，也不能排除非线性关联。

## 七、结论表达与边界

- 主张：如果拒绝 H0，则可称数据支持年龄与最大运动心率存在线性统计关联；如果未拒绝，则称证据不足以拒绝零线性斜率。
- 证据：如果完成分析，则报告实际有效样本数、斜率、95% 置信区间和 p 值；目前没有本题的实际分析结果。
- 推理：如果模型诊断基本合理，则结合斜率方向、区间和敏感性分析解释关联的方向、精度与稳健性。
- 边界：即使关联显著，也不能证明因果；选择偏倚、未测量混杂、中心差异和缺失限制解释与推广。

统计显著不等于临床重要，应结合效应大小、区间、测量误差和临床背景评估。更强的结论需要独立样本复现、更完整的体能与用药等信息，以及针对具体因果问题的适当设计。
