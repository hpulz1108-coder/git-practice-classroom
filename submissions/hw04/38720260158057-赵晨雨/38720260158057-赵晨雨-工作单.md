## 任务 1：降维是为了看图，还是预测新样本？

| 目的 | 需要的输出 | 如何判断有用 |
|---|---|---|
| 可视化 | 低维坐标图、样本编号和拟合后用于着色的标签 | 是否便于观察分布、邻近关系和异常点；不要求类别完全分开 |
| 去噪 | 去掉部分变化后的重建数据或低维表示 | 在未参与拟合的数据或后续任务上检查有用信号是否保留、噪声是否减少 |
| 压缩特征 | 维度更少的表示 | 检查维度/存储减少的同时，信息保留比例和后续任务表现是否可接受 |
| 探索样本结构 | 样本低维位置、邻域或候选分组 | 检查结构对参数、随机种子和样本扰动的稳定性；候选簇不是机制证据 |
| 作为模型输入 | 训练得到的变换及新样本预测 | 在严格隔离的验证数据上评价预测指标，且变换只能在训练折拟合 |

描述性降维流程：表达矩阵 → 全部 72 个样本上拟合标准化与 PCA/UMAP → 拟合完成后诊断着色 → 描述当前样本。

预测新样本流程：先划分训练/验证 → 每个训练折内拟合标准化、PCA 与分类器 → 转换并预测验证折 → 固定方案后评估独立测试集。

即使 PCA 不用诊断标签，全数据标准化/PCA 仍会利用验证样本的特征分布来估计均值、尺度和主成分方向；验证折参与了表示构建，因此不再是严格的折外评估。把所有拟合步骤放进 Pipeline，并只在每个训练折拟合，可以避免此类信息泄露。

### 原尺度（仅中心化）对照

- 原尺度 PC1、PC2 解释率分别为 `17.4278%`、`10.3386%`，合计 `27.7664%`。
- 原尺度 PC1 绝对权重最大的探针为：`M25079_s_at`（+0.352388）、`hum_alu_at`（+0.313552）、`HG1428-HT1428_s_at`（+0.234867）、`L06499_at`（+0.210453）、`J04617_s_at`（+0.196253）。
- 两种尺度处理的解释率和高权重探针不同，表明原尺度 PCA 更受高方差探针影响。标准化让各探针尺度可比较，但也可能放大低变异噪声；它不一定在所有数据场景下都更好。

PC1 的解释：PC1 是当前标准化表达矩阵中样本方差最大的线性方向；每个样本的 PC1 得分由标准化探针值按 PC1 权重加权得到。

不能据此推出：PC1 不等于最能区分 ALL/AML 的方向，也不代表某一个基因。探针名不等于基因名，探针权重不能直接解释为致病作用。主成分整体变号只会同时翻转得分与权重，不改变解释率或几何关系。中心化的 72 行数据矩阵秩最多为 71，因此至多有 71 个非零主成分。

## 任务 3：UMAP 上的簇可以相信到什么程度？

所有 UMAP 使用同一份标准化矩阵和全部 72 个样本；没有按诊断筛选探针。基线为 `n_neighbors=15`、`min_dist=0.1`、`metric='euclidean'`、`random_state=42`、`n_jobs=1`，每次对照只改变一个因素。

| 对照维度 | PCA | UMAP |
|---|---|---|
| 线性/非线性 | 线性变换 | 非线性嵌入 |
| 优化或保留的主要信息 | 依次最大化总体方差 | 主要服务于局部邻域结构展示 |
| 坐标轴含义 | 主成分方向是输入特征的线性组合 | 坐标轴无直接物理含义 |
| 方差解释率 | 可报告每个 PC 的解释率；本次前两维合计 24.37% | 不提供 PCA 式方差解释率 |
| 局部邻域与全局距离 | 投影会丢失信息，二维距离不等于完整高维距离 | 邻近点可作探索；全局距离、岛屿间距、方向和面积不可直接解释 |
| 参数与随机性 | 主要由输入尺度、保留维数和拟合数据决定；此处完整 PCA 使用确定性求解 | `n_neighbors`、`min_dist` 及随机种子会影响嵌入；本次按单因素比较 |
| 用于预测时如何避免泄露 | 标准化、PCA 与分类器放进 Pipeline，只在各训练折拟合 | 若作为预测流程的一部分，同样只在训练折拟合 UMAP/预处理/模型；验证折只 transform，不参与拟合或调参 |

### UMAP 参数/随机种子单因素对照

| 运行 | 参数变化 | 与基线相比每样本 10 近邻 Jaccard 均值 / 中位数 |
|---|---|---:|
| 基线 | `n_neighbors=15`, `min_dist=0.1`, seed 42 | — |
| 邻居数对照 | `n_neighbors=5` | 0.471 / 0.538 |
| `min_dist` 对照 | `min_dist=0.5` | 0.538 / 0.538 |
| 种子对照 | `random_state=7` | 0.541 / 0.538 |

Jaccard 衡量每个样本在二维图中 10 个最近邻集合的重合比例；均值约 0.47–0.54 表示邻域有部分重合，但并非完全不变。基线图可见一定类别分离但仍有混合；参数变化后形状和局部邻近关系改变。不能仅选择视觉上分组最明显的图汇报。

- UMAP 常用于展示复杂高维数据的局部结构，例如单细胞数据中的候选相似群体；这种展示用途不等同于发现机制。
- 岛屿数量、岛屿间距离、方向和面积会受参数和随机性影响，不能直接解释为真实亚型数量、组间生物距离或重要性。
- 图上分离不能证明疾病机制，也不能证明预测新患者的性能。
- 本数据缺少可用于核对的中心/批次字段，因此不能声称已排除批次影响。

## 三道作业：用自己的话回答

1. **PCA 第一主成分代表什么？**我把 PC1 理解成一条新的综合坐标轴：它把很多探针按不同权重加起来，让这 72 个样本在这条轴上的差异尽量大。本次 PC1 解释了约 `14.92%` 的总体变化；例如 `X92518_s_at` 的 PC1 方向权重约为 `+0.0288`。这个权重说明该探针参与了这条坐标轴，不代表它是致病基因，也不说明 PC1 一定最能区分 ALL 和 AML。

2. **为什么 PCA 前考虑标准化？**不同探针的数值范围可能差很多；不标准化时，数值变化大的探针容易主导 PCA。标准化后每个探针都调整到相近尺度，更容易比较。本次标准化 PCA 前两轴合计解释约 `24.37%` 变化，原尺度 PCA 前两轴合计约 `27.77%`，而两者 PC1 权重靠前的探针也不同，说明处理尺度会改变结果。标准化也可能把本来变化很小的噪声放大，所以要结合数据和目的判断，不能说标准化总是更好。

3. **UMAP 能说明什么、不能说明什么？**我把 UMAP 当作观察样本局部相似关系的一种地图：靠得近的点可以作为进一步查看的线索，但地图上的方向、岛屿大小和岛屿之间距离不应直接当成真实生物距离。本次改邻居数、`min_dist` 或随机种子后，10 近邻集合和基线只有部分重合，说明图形会受设置影响。因此 UMAP 图不能单独证明疾病机制、真实亚型数量、已排除批次影响或能预测新患者。
