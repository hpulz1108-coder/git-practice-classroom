## 二、最终结论

- 主张：二维PCA或UMAP图可以用于探索这72份白血病样本的表达结构，但图上出现分离本身不足以证明疾病机制、真实亚型数量或对新患者的预测能力。
- 证据：标准化PCA的PC1和PC2分别解释14.92%和9.45%的总方差，合计24.37%；PC1绝对权重最大的探针X92518_s_at的方向权重约为0.02879，而UMAP对照分别改变邻居数、最小距离和随机种子。
- 推理：PCA提取的是无监督的高方差线性方向，UMAP呈现的是受参数影响的局部邻域结构，因此只有在不同设置下仍可重复的邻近关系，才适合作为后续假设的线索。
- 边界：本分析缺少批次信息和独立验证队列，不能据此排除批次影响或推断临床泛化；下一步应结合批次及临床元数据，并在预先固定的流程中使用独立队列验证。

## 四、结论边界

- **本次结果能够支持：**在这72份白血病样本中，标准化PCA的前两主成分分别解释14.9%和9.4%的方差，ALL与AML在二维PCA图中仍有较多重叠。UMAP基线图显示出较明显的局部聚集和诊断组分离，但改变 `n_neighbors`、`min_dist` 或随机种子后，整体布局和聚集形态也随之变化。因此，这些图可用于探索样本结构、提出后续验证假设；UMAP中的局部关系需要结合近邻重合分析进一步确认。

- **本次结果不能证明：**图上分离不能证明发现了疾病机制或真实亚型数量，也不能证明模型能够预测新患者。UMAP图中的岛屿数量、岛屿间距离、方向和面积不能直接解释为真实的生物学距离或群体差异。由于数据没有批次字段，也不能据此宣称已排除批次、样本处理或测量流程的影响。

- **下一步最需要补充的验证：**补充样本批次、处理流程和临床元数据，检查分离是否与这些因素相关；在独立样本或独立队列中重复分析，评估局部结构和候选分组能否复现。若研究目标包括预测新患者，应预先固定分析方案，将标准化、PCA及分类器放入交叉验证流程，在训练折内拟合，并用未参与方案选择的独立测试数据评价预测表现。
