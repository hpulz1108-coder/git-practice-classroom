## 二、最终结论

- 主张：当前二维 PCA/UMAP 图中的 ALL/AML 分离可以作为探索样本结构的线索，但不能据此断定已经发现疾病机制或能够预测新患者。
- 证据：标准化 PCA 的 PC1 和 PC2 分别解释 14.92% 和 9.45% 的总方差，合计 24.37%；UMAP 将 `n_neighbors` 从15改为5时，与基线共享的10近邻比例平均为62.08%，说明嵌入结果会随设置改变。
- 推理：PCA 前两轴只保留了部分总体变异，UMAP 主要保留部分局部邻域关系且对参数和随机种子敏感，因此二维布局是当前分析设置下的一种表示，不等同于完整的生物学关系。
- 边界：要评价新患者预测能力，必须在训练折内拟合完整预处理和模型，并在未参与模型选择的独立患者数据上验证；要把图中模式提升为机制结论，还需要候选标志物的功能实验或临床证据。

## 三、关键结果索引

- PCA（PC1、PC2 解释率及累计解释率）：使用全部72个样本和7,129个探针的标准化矩阵，PC1为14.92%，PC2为9.45%，前两项合计24.37%；累计解释率曲线和散点图保存在分析 notebook 的任务2输出中。
- PC1 绝对权重最大的5个探针：`X92518_s_at`（+0.028786）、`X95190_at`（−0.028177）、`X98253_at`（+0.027927）、`X82895_at`（+0.027871）、`Y09616_at`（+0.027757）。
- 原尺度 PCA 对照：仅中心化、不标准化时，PC1为17.43%，PC2为10.34%，前两项合计27.77%；PC1前5个高权重探针为 `M25079_s_at`、`hum_alu_at`、`HG1428-HT1428_s_at`、`L06499_at`、`J04617_s_at`。两种尺度的权重名单不同，说明大方差特征会影响原尺度 PCA。
- UMAP 参数/种子对照：基线为 `n_neighbors=15`、`min_dist=0.1`、`metric='euclidean'`、`random_state=42`、`n_jobs=1`；三个单因素对照分别将邻居数改为5、`min_dist`改为0.5、随机种子改为7。相对基线的平均共享10近邻比例分别为62.08%、67.64%、67.64%，中位数均为70%；四种设置共同保留205对无向近邻关系。
- 可选交叉验证结果：仅使用原始38个训练样本，采用 `StratifiedKFold(3, shuffle=True, random_state=42)`。`StandardScaler → 1NN` 的三折 balanced accuracy 为0.8194、0.8750、0.8333，均值0.8426；`StandardScaler → PCA(10, svd_solver='full') → 1NN` 为0.6944、0.7639、0.8333，均值0.7639。该结果是小样本探索性比较，不代表独立确认性测试。

## 四、结论边界

- 本次结果能够支持：在当前72个样本、7,129个探针、标准化方式和所列 PCA/UMAP 参数下，样本具有可视化的总体结构和部分重复出现的局部邻近关系；ALL/AML 的分离可以作为进一步验证的探索线索。
- 本次结果不能证明：PC1 是最能区分 ALL/AML 的方向、某个探针是致病基因、UMAP 中的岛屿等于真实亚型、岛屿间距离等于生物学距离、存在疾病机制，或模型对新患者具有已知预测性能。数据缺少可用的批次/中心字段，也不能据此宣称已经排除批次效应。
- 下一步最需要补充的验证：预先锁定全流程后，在独立、多中心、患者级队列上评估预测性能；同时记录批次和中心信息，并对候选标志物开展功能实验或其他外部生物学验证。
