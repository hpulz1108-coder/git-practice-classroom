## 二、最终结论

- 主张：不同意“图上分得开就同时证明疾病机制和新患者预测能力”；本次 PCA 与 UMAP 只能提供当前 72 份表达记录的探索性结构证据。
- 证据：按 7,129 个探针 z-score 后，PC1、PC2 分别解释 14.9216% 和 9.4462%，合计 24.3678%；PC1 最大绝对方向权重是 `X92518_s_at` 的 +0.028786。UMAP 将 `n_neighbors` 从 15 改为 5 后，每个样本的二维 5 近邻集合相对基线的平均 Jaccard 仅 0.4311；只改 `min_dist=0.5` 或种子为 7 时分别为 0.5182 和 0.4716，布局与局部邻居均有变化。
- 推理：PCA 最大化的是当前输入的总体投影方差，UMAP 重点近似局部邻域；两者都没有把疾病机制、因果作用或未见患者表现作为优化目标，因此标签着色后的视觉分离最多支持提出候选结构。
- 边界：数据缺少患者重复映射、中心和批次字段，且 72 行均参与了描述性拟合；下一步应在独立多中心队列中锁定流程做患者级外部验证，并对候选探针或通路开展独立表达复现与功能实验。

## 三、关键结果索引

- PCA（PC1、PC2 解释率及累计解释率）：PC1=0.149216，PC2=0.094462，前两项合计=0.243678；累计达到 50%、80%、90%、95% 分别需要 11、37、51、60 个主成分。
- PC1 绝对权重最大的 5 个探针：`X92518_s_at` +0.028786；`X95190_at` −0.028177；`X98253_at` +0.027927；`X82895_at` +0.027871；`Y09616_at` +0.027757。本作业按 `components_.T` 定义方向权重。
- 原尺度 PCA 对照：PC1=0.174278，PC2=0.103386，合计=0.277664；前五项为 `M25079_s_at` +0.352388、`hum_alu_at` +0.313552、`HG1428-HT1428_s_at` +0.234867、`L06499_at` +0.210453、`J04617_s_at` +0.196253，与标准化结果前五项无重叠。
- UMAP 参数/种子对照：基线为 `n_neighbors=15, min_dist=0.1, metric='euclidean', random_state=42, n_jobs=1`。相对基线的平均二维 5-NN Jaccard：`n_neighbors=5` 为 0.4311，`min_dist=0.5` 为 0.5182，`random_state=7` 为 0.4716。四种设置下，63/72 个样本至少保留 1 个共同的二维 5 近邻，平均保留 1.944 个；局部关系部分稳定，但整体布局、轴方向、岛屿间距和类别混合方式明显改变。
- 可选交叉验证结果：只在原始 38 个 train 样本内，固定分层三折。`StandardScaler → 1NN` 各折 balanced accuracy 为 0.819444、0.875000、0.833333，均值 0.842593；`StandardScaler → PCA(10) → 1NN` 为 0.694444、0.763889、0.833333，均值 0.763889。全部步骤均在折内拟合，未读取 34 个原始 test 标签评分或调参。

## 四、结论边界

- 本次结果能够支持：描述这 72 份教学样本在规定输入、标准化和参数下的主要线性变化与候选局部邻域；量化尺度、UMAP 参数和随机种子变化对图形的影响；说明本次 PCA(10) 在训练内三折中没有优于同一 1-NN 基线。
- 本次结果不能证明：高 loading 探针是致病基因或显著差异基因；图中岛屿是真实亚型；ALL/AML 的视觉分离来自疾病而非批次等混杂；72 行对应 72 名已核验独立患者；图形可以预测新患者或达到临床部署要求。
- 下一步最需要补充的验证：在含患者、中心、批次信息的独立外部队列中，预先锁定预处理、模型和阈值，做患者级验证；随后对稳定候选信号进行跨平台表达复现和功能实验。
