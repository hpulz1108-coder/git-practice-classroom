### 1.1 目标—输出—评价表

| 目标 | 需要什么输出 | 如何判断有用 |
|---|---|---|
| 可视化 | 低维坐标及按诊断着色的散点图 | 相似样本是否靠近；结构能否在不同参数下重复；能否追踪同一样本 |
| 去噪 | 降维后的重建结果或下游验证结果 | 验证表现是否改善；重建误差和信号保留程度是否合理 |
| 压缩特征 | 少量主成分或嵌入维度 | 在可接受的信息损失下，是否明显减少维度、存储量和计算量 |
| 发现样本结构 | 候选邻域、连续梯度、离群点或簇 | 是否能在不同参数、随机种子或独立数据中复现，并排除批次等混杂因素 |
| 作为后续模型输入 | 在训练折内拟合的降维器和验证分数 | 严格交叉验证或独立测试中的泛化表现是否改善 |

### 1.2 两条流程

1. 描述当前 72 个样本：`72×7,129 表达矩阵 → 在全部 72 行上拟合列标准化 → 在全部 72 行上拟合 PCA/UMAP → 拟合完成后按 diagnosis 着色`。这条流程只描述当前样本，不代表对新患者的预测能力。
2. 评估新样本预测：`先划分训练折和验证折 → 只在训练折拟合 StandardScaler、PCA 与分类器 → 用训练折得到的变换处理验证折 → 预测并计算 balanced accuracy → 固定方案后再评估独立测试集`。

### 1.3 为什么全数据 PCA 会泄露信息

PCA 虽然不使用诊断标签，但如果先在全部数据上做标准化和 PCA，列均值、标准差以及主成分方向都会利用验证折的特征分布。也就是说，验证折已经参与了表示学习，交叉验证分数就不再代表模型面对真正未见样本时的表现。因此，`StandardScaler`、PCA 和分类器都必须放入同一个 Pipeline，并在每个训练折内重新拟合。

### 1.4 可选三折验证结果

仅使用原始 38 个训练样本，采用 `StratifiedKFold(3, shuffle=True, random_state=42)`；原始 34 个测试样本没有用于本次调参或评分。

| 方法 | 第 1 折 | 第 2 折 | 第 3 折 | 均值 |
|---|---:|---:|---:|---:|
| `StandardScaler → 1NN` | 0.819444 | 0.875000 | 0.833333 | 0.842593 |
| `StandardScaler → PCA(10) → 1NN` | 0.694444 | 0.763889 | 0.833333 | 0.763889 |

这次小样本对照中，加入 10 维 PCA 后平均 balanced accuracy 没有提高。不过训练样本只有 38 个，结果只能作为本次流程示范，不能据此断定 PCA 在其他数据或模型中一定无用。

### 3.3 PCA 与 UMAP 比较

| 比较点 | PCA | UMAP |
|---|---|---|
| 方法 | 线性 | 非线性 |
| 主要保留或优化的信息 | 依次最大化投影方差 | 尽量保留局部模糊邻域结构 |
| 坐标轴含义 | 主成分方向，可对应探针权重 | UMAP1/UMAP2 本身没有固定生物学含义 |
| 能否报告方差解释率 | 可以 | 不可以 |
| 局部与全局解读 | 全局线性结构相对容易解释 | 优先保留局部邻域；全局距离、方向和面积要谨慎解释 |
| 参数与随机性 | 给定数据和求解器时相对稳定，但符号可整体翻转 | 对邻居数、`min_dist` 和随机种子敏感 |
| 用于预测时如何避免泄露 | 在每个训练折内拟合 | 同样必须在每个训练折内拟合，并考虑新样本转换方法 |

### 3.4 问题回答

1. 跨不同参数和种子仍重复出现的局部邻居更值得后续核查，例如 G004 与 G001、G007、G008、G027、G049 的关系。
2. 岛屿数量、岛屿间距离、方向和面积并不稳定。UMAP 坐标还可能整体旋转或翻转，所以这些视觉元素不能直接当作真实亚型数量或生物距离。
3. UMAP 常用于单细胞或复杂表型展示，是因为它能把高维、可能非线性的局部邻域压缩到二维，便于提出候选群体、连续梯度和离群点。
4. 图上分离不能单独证明疾病机制、真实亚型数量或新患者预测性能。这些结论分别需要独立队列复现、探针注释及功能实验、严格交叉验证和外部测试。
5. 本数据没有批次、实验中心等字段，因此不能宣称已经排除批次影响。

### 4.1 主张—证据—推理—边界

2. **为什么 PCA 前通常需要考虑标准化？**标准化可以避免大尺度或大方差探针仅凭数值尺度主导结果。本次标准化 PCA 前两维解释 24.368%，仅中心化的原尺度 PCA 前两维解释 27.766%，最高权重探针也从 `X92518_s_at` 变成 `M25079_s_at`，说明尺度确实影响主成分方向。它的代价是可能放大低变异噪声，因此不能机械地认为标准化永远更好。
3. **UMAP 图能说明什么，不能说明什么？**UMAP 可以展示当前数据中候选的局部邻域、连续趋势和离群点，但不能单独证明疾病机制、真实亚型数量、批次影响已经排除或模型能预测新患者。邻居数改为 5 后，相对基线的平均 5 近邻重合率为 0.542；随机种子改为 7 后为 0.636，说明有些局部关系可以复现，另一些会随设置改变。
