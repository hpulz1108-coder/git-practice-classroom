## 二、最终结论

- 主张：二维图分开只能说明当前样本在特定方法和设置下出现低维结构，不能直接证明疾病机制或新患者预测能力。
- 证据：标准化 PCA 的 PC1、PC2 分别解释 14.922% 和 9.446% 的方差；UMAP 将邻居数从 15 改为 5 后，与基线的平均 5 近邻重合率为 0.542，种子改为 7 时为 0.636。
- 推理：降维会压缩并丢失信息，UMAP 还会随参数和随机性改变，所以视觉分离只能用于提出候选结构，不能替代机制验证和预测评估。
- 边界：需要带批次信息的独立患者队列复现、功能/通路验证，以及严格嵌套验证和外部测试。
