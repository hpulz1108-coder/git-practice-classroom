## 任务 1：降维是为了看图，还是预测新样本？

### 1.1 目标—输出—评价表

| 目的 | 需要什么输出 | 如何判断有用 |
|---|---|---|
| 可视化 | 二维或三维坐标；轴标注该轴解释率（PCA）或明确说明无解释率（UMAP）；坐标与 `sample_id` 的对应表 | 换参数或种子后结构是否重现；能否指出某个点是哪个样本；不把轴或簇的位置当成生物学量 |
| 去噪 | 保留前若干主成分的重建矩阵，或低方差/低稳定方向被削弱的表示 | 需要重复测量或下游实验验证；“图看起来更整齐”不是证据，且标准化的代价是可能放大低变异噪声 |
| 压缩特征 | 较少坐标、重建误差、累计解释率、对新样本可施加的同一变换 | 同一下游任务上用更少维数得到不劣的表现，同时计算与存储成本下降 |
| 发现样本结构 | 邻域关系、候选分组、梯度、离群点 | 邻域和分组在参数、种子、独立批次下是否重现；需外部信息（临床、遗传学、批次）确认 |
| 作为后续模型输入 | 训练阶段拟合好的标准化 + PCA，可对新样本 `transform` 的特征 | 全流程放进 Pipeline、折内拟合的交叉验证，以及固定方案后只用一次的独立测试集 |

### 1.2 两条流程（标出拟合范围）

**流程 A：描述这 72 个样本（允许全数据拟合）**

```
表达矩阵 72×7129
   │   ← 拟合范围：全部 72 行
StandardScaler().fit_transform  →  Z
   │   ← 拟合范围：全部 72 行
PCA(svd_solver='full') / UMAP(...)  →  二维坐标
   │   ← 标签不参与任何一步拟合
用 diagnosis 事后着色
```

**流程 B：评估新样本预测（必须折内拟合）**

```
先划分 train / test
   │
对每个训练折：
   ├─ StandardScaler().fit(训练折) → transform(训练折) / transform(验证折)
   ├─ PCA(...).fit(训练折标准化后)  → transform(训练折) / transform(验证折)
   └─ 分类器.fit(训练折的降维结果)
   │
预测验证折 → 汇总交叉验证指标
   │
固定方案后，只在测试集上评估一次
```

拟合范围只有训练折；验证折只做 `transform` / `predict`，不参与任何 `fit`。

### 1.3 为什么“PCA 没用标签，所以可以全数据先 PCA 再交叉验证”仍然泄露

PCA 的每一列均值 μ、标准差 s 与协方差矩阵，都是从喂进去的**所有样本**算出来的。在全 72 行上 `fit` 之后再交叉验证，验证折的观测已经进入过 μ、s 和主成分方向的估计，主成分因此朝着“包含验证折”的方向倾斜，验证折不再是没见过的数据，分数偏乐观。**标签没有被使用，不代表样本信息没有被使用。** 正确做法是把 `StandardScaler` 和 `PCA` 都放进 `Pipeline`，让它们在每折内单独 `fit`。

### 1.4 可选验证（只在原始 38 个训练样本内）

`StratifiedKFold(n_splits=3, shuffle=True, random_state=42)`，全部步骤用 `make_pipeline` 放进训练折内拟合，未读取原始测试标签。

|---|---|---|
| 1 | 0.8194 | 0.6944 |
| 2 | 0.8750 | 0.7639 |
| 3 | 0.8333 | 0.8333 |
| **均值（min–max）** | **0.8426**（0.8194–0.8750） | **0.7639**（0.6944–0.8333） |

逐折：全探针胜 2 折、平 1 折、PCA(10) 胜 0 折。**但只有 3 折、n=38，样本量太小，不足以据此给两种方案排名**，只能说这次没有观察到 PCA(10) 更好。训练折 BA 恒为 1.0000，因为 1 近邻在训练集上以自己的距离 0 为最近邻，这个数字不含模型优劣信息。

## 任务 2：PCA 保留了什么，又丢掉了什么？

### 2.1 标准化检查

`StandardScaler` 用总体标准差（ddof=0）。变换后：列均值最大绝对偏差 **5.983×10⁻¹⁶**，列标准差与 1 的最大偏差 **3.331×10⁻¹⁶**，整体均值 −6.212×10⁻¹⁹、整体标准差 1.000000，无常量列。

标准化与微阵列上游归一化**不是一步**：标准化只把每一列换算成“自身标准差”为单位，不改变跨样本的相对结构，也不处理背景校正、批次或探针杂交效率。本数据含负值，不是 RNA-seq 原始计数，因此不取 log/log1p。

### 2.2 解释率与累计解释率

| 指标 | 数值 |
|---|---|
| PC1 explained variance ratio | **0.149216（14.9216%）** |
| PC2 explained variance ratio | **0.094462（9.4462%）** |
| PC1 + PC2 | **0.243678（24.3678%）** |
| PC1 方差 / PC2 方差 / 总方差（迹） | 1078.7424 / 682.9024 / 7229.4 |

累计解释率：前 3 个 29.04%、前 5 个 36.50%、前 10 个 49.18%、前 20 个 64.13%、前 50 个 89.72%、前 71 个 100%。

### 2.3 PC1 绝对权重最大的 5 个探针

按工作单口径，loading = `pca.components_.T`，即主成分方向权重（不是乘以主成分标准差后的口径，也不是变量与主成分的相关系数）。

| 探针 | PC1 带符号权重 | \|权重\| |
|---|---|---|
| `X92518_s_at` | **+0.028786** | 0.028786 |
| `X95190_at` | **−0.028177** | 0.028177 |
| `X98253_at` | **+0.027927** | 0.027927 |
| `X82895_at` | **+0.027871** | 0.027871 |
| `Y09616_at` | **+0.027757** | 0.027757 |

全部 7129 个权重的绝对值中位数 0.008561、最大 0.028786——最大权重只是中位数的约 3.4 倍，没有哪个探针单独主导 PC1。

**样本的 PC1 得分如何由标准化特征加权得到**：`PC1_i = Σ_j w_j · z_ij`。开卷核验：样本 G001 手算得 27.105207，`sklearn` 给出 27.105207，差 3.9×10⁻¹⁴。而只用这 5 个权重最大的探针相加，同一得分只有 0.1351，即真值的 **0.5%**——单个权重再大，也只是和里的一项。

### 2.4 原尺度 PCA 对照（仅中心化、不标准化）

| 口径 | PC1 | PC2 | 前二合计 |
|---|---|---|---|
| 标准化 | 14.922% | 9.446% | 24.368% |
| 原尺度（仅中心化） | **17.428%** | **10.339%** | **27.766%** |

原尺度 PC1 权重前五：`M25079_s_at`(+0.352388)、`hum_alu_at`(+0.313552)、`HG1428-HT1428_s_at`(+0.234867)、`L06499_at`(+0.210453)、`J04617_s_at`(+0.196253)，与标准化口径的 top5 **零重叠**。

原因：原数据各列方差最小 7.032×10²、中位数 3.386×10⁴、最大 2.491×10⁸，**最大是最小的 354,257 倍**。不标准化时，方差最大的少数几列直接支配 PC1 的方向。

**一个必须如实报告的意外**：原尺度 PC2 的单阈值最优 BA 为 **0.9494**，远高于标准化 PC2 的 **0.4894**；原尺度前两维的留一 1NN BA 为 **0.9081**，标准化后只有 **0.6430**。也就是说，在这份数据里方差最大的列同时也带着判别信息，标准化把它们压到与其余列同样的权重，反而稀释了信号。

但这不能反推“原尺度更好”，有三点限制：(a) 阈值是在全部 72 行上、看过标签之后挑的，属于事后描述，不是模型评价；(b) 原尺度 PC 方向由少数几列主导，`hum_alu_at` 是 Alu 重复序列探针，这类高丰度/管家类信号也可能携带 RNA 投入量、杂交效率等技术差异，在本数据里无法与疾病信号分开；(c) 要判断口径优劣必须在训练折内拟合、在独立样本上比较，不能用同一批样本的事后 BA 排名。

**作用与代价**：标准化的作用是让 7129 列在同一把尺子上加权，主成分反映**相关结构**而非量纲；代价是把低变异列（可能主要是测量噪声）的相对权重放大到与真实信号列相同，也可能像本例这样削弱“大方差列里顺带的判别信号”。因此两种口径都保留并写明差异，而不是只报解释率更高的那个。

### 2.5 问题回答

**PC1 最大化的是什么方差？** 在单位长度约束下，使投影 `t₁ = Z w₁` 的方差最大的那个方向的方差。实测 PC1 方差 1078.7424，占总方差（迹 7229.4）的 14.92%。

**它是否等于“最能区分 ALL/AML 的方向”或某一个基因？** 都不是。沿 PC1 单阈值分类的最优 BA 只有 **0.7123**，而沿类别均值差方向可达 **0.9281**，两个方向的 |cos| 只有 **0.3841**，PC1 只承载了判别方向能量的 **14.75%**（0.3841²）。它更不是某一个基因——PC1 是全部 7129 个探针的加权和，最大权重也只占和里的一小项。

**主成分符号整体翻转是否改变结果？** 不改变。`w` 与 `−w` 张成同一个一维子空间，投影得分同时变号，解释率、样本间距离、PC1–PC2 平面本身都不变，只有 loading 表和散点图的符号翻过来。所以看到权重是正是负，不能直接解释成“上调/下调”，必须先固定朝向约定。

**中心化后的 72 个样本为什么至多有 71 个非零主成分？** 中心化把所有样本平移到“过原点、不含 (1,…,1) 方向”的子空间里，该子空间维数最多为 n−1 = 71，主成分个数受 min(n−1, p) 限制。实测 `np.linalg.matrix_rank(Z) = 71`；`sklearn` 仍返回 72 个分量，第 72 个方差 2.127×10⁻²⁸、解释率 2.94×10⁻³²，是数值零。

**一句对 PC1 的解释**：PC1 是全部 7129 个探针 z 分数的加权和，权重绝对值最大的是 `X92518_s_at`（+0.0288），样本得分范围 −55.340 ~ +91.383，它只解释了总方差的 14.9216%。

**一句不能据此推出的结论**：不能因为 `X92518_s_at` 在 PC1 上权重最大，就说它与白血病相关或可作标志物——把权重前 5 的探针加起来也只复现样本 G001 得分的 0.5%，而 PC1 本身也不是最能区分两类的方向。

## 任务 3：UMAP 上的簇可以相信到什么程度？

### 3.1 PCA 与 UMAP 比较表

| 比较项 | PCA | UMAP |
|---|---|---|
| 线性/非线性 | 线性投影（正交方向） | 非线性流形嵌入 |
| 优化或保留的主要信息 | 逐步最大化投影方差，全局结构优先 | 尽量保留 k 近邻图（局部邻域） |
| 坐标轴含义 | 可追踪：每轴是 7129 个探针的确定权重组合 | 无固定含义，UMAP1/UMAP2 不是基因轴或疾病轴 |
| 能否报告方差解释率 | 能，PC1 14.92%、PC2 9.45% | 不能，没有与 PCA 等价的总方差口径 |
| 局部邻域与全局距离的解读 | 距离可比，但前两轴只覆盖 24.37% 的方差 | 局部近邻可参考；岛间距、面积、朝向、点密度都不能量化生物学差异 |
| 参数与随机性 | 确定性（`svd_solver='full'`，无随机性） | 受 `n_neighbors`、`min_dist`、度量与随机种子共同影响 |
| 用于预测时如何避免泄露 | 训练折内 `fit`，再 `transform` 验证折 | 同样必须在训练数据上 `fit`，并固定全部参数 |

### 3.2 参数与种子对照

同一标准化矩阵 Z（不按诊断筛选探针），`metric='euclidean'`、`n_jobs=1`：

| 运行 | 坐标范围 | 与基线 10 近邻 Jaccard | kNN 图连通分量（k=3 / k=5） |
|---|---|---|---|
| 基线 nn=15, md=0.1, seed=42 | x∈[−4.39, 0.06]，y∈[14.54, 18.80] | 1.000 | 1 / 1 |
| 只改 `n_neighbors=5` | x∈[1.71, 8.19]，y∈[4.87, 10.49] | 0.499 | **4 / 2** |
| 只改 `min_dist=0.5` | x∈[−5.78, −0.45]，y∈[−5.82, 0.34] | 0.507 | 1 / 1 |
| 只改 `random_state=7` | x∈[7.29, 11.62]，y∈[0.07, 5.17] | 0.606 | 1 / 1 |

同参数重复运行的最大坐标差 **0.000×10⁰**（`n_jobs=1` + 固定种子可完全复现）。并排图见 `fig-pca-vs-umap-variants.png`；坐标与样本编号的对应表保存为 `task3-coordinates.csv`（72 行，含 `sample_id`、`diagnosis`、`original_split`、PC1/PC2、raw_PC1 与四套 UMAP 坐标）。

### 3.3 问题回答

**哪些邻近关系在不同设置下较稳定？** 以每个样本的 10 近邻集合的 Jaccard 一致度计：改种子（42→7）后与基线重合 **0.606**，改 `min_dist`（0.1→0.5）后 **0.507**，改 `n_neighbors`（15→5）后 **0.499**。大约一半的局部近邻关系稳定，另一半随设置漂移，其中随机种子的影响反而最小。与高维原空间的“真实”10 近邻相比，基线 UMAP 只重合 **0.344**，二维 PCA 只重合 **0.282**——二维图都丢掉约三分之二以上的高维邻域关系。

**岛屿数量、岛屿间距离、方向和面积是否稳定？** 都不稳定，且可以用“每个点连最近 k 个点、数连通分量”量化（参数只有 k）：

| 运行 | k=3 分量数 | k=5 分量数 | 分量大小 |
|---|---|---|---|
| 基线 | 1 | 1 | 72 |
| 只改 `n_neighbors=5` | **4** | **2** | 27 / 27 / 10 / 8（k=3）；64 / 8（k=5） |
| 只改 `min_dist=0.5` | 1 | 1 | 72 |
| 只改 `random_state=7` | 1 | 1 | 72 |

**基线在两种定义下都只有一个连通团块**；只有把 `n_neighbors` 降到 5 才裂出多个岛——k=5 时那个 8 点孤岛**全部是 ALL**。同一份数据、同一套预处理，岛数在 1 到 4 之间随一个参数跳动，所以不能数“图上有几个岛”就断言有几个亚型。

方向与面积同样不稳定：四次运行的坐标范围互不相同，整体平移、旋转甚至翻转，说明**方向和绝对位置没有意义**，岛间距不能当作生物学距离。另一个佐证是类间/类内平均距离比：原始 7129 维 1.038、二维 PCA 1.133、UMAP 基线 1.230、`n_neighbors=5` 1.499——分离度是算法把类内压紧之后才显得明显的。

**为什么 UMAP 常用于单细胞或复杂表型展示？** 它擅长把高维中“谁和谁是近邻”的局部关系压到二维，对非线性、连续谱系比线性 PCA 更直观，计算上可扩展到大量细胞，适合**探索性展示**与提出亚群假设。

**图上分离能否证明疾病机制、真实亚型数量或新患者预测性能？** 都不能。二维坐标上的留一 1NN BA（PCA 0.6430、UMAP 基线 0.8268、`n_neighbors=5` 0.8255、`min_dist=0.5` 0.8174、种子 7 为 0.8055）只是**描述性核对**，不是对新患者的预测性能；真正的预测必须在折内拟合的 Pipeline 加独立测试集上评价。降维图只能提出假设。

**本数据缺少批次字段，能否宣称已经排除批次影响？** 不能。数据没有采集批次、芯片批次或处理时间字段，任何分组差异都可能来自批次；无法观测就无法排除，也就不存在“已经排除”的证据。

### 3.4 三条“图能支持什么／不能支持什么”

1. **能支持**：在这批 72 个样本、这套预处理与参数下，ALL 与 AML 的局部邻域在一定程度上分开（类间/类内平均距离比：原始 7129 维 1.038 → UMAP 基线 1.230），可作为“两类表达谱存在差异”的**探索性线索**。
2. **不能支持**：不能由岛屿数量推断亚型数，也不能把岛间距、面积、朝向当生物学差异——改种子或改 `n_neighbors` 后 10 近邻只保留 0.499–0.606，连通分量数从 1 跳到 4。
3. **不能支持**：不能由二维图宣称对新患者有预测能力或发现了机制。预测能力需要折内拟合的 Pipeline 加独立测试集；机制需要独立的生物学实验。

## 任务 4：给研究团队写一份结论

- **主张**：二维图上分得开，只给出关于这 72 个样本的一个可探索假设，既不证明疾病机制，也不等于能预测新患者。
- **证据**：PC1+PC2 只解释总方差的 24.37%（PC1 14.92%、PC2 9.45%）；PC1 上权重最大的探针 `X92518_s_at`(+0.028786) 只是加权和里的一项，前 5 个探针相加只复现样本 G001 的 PC1 得分的 0.5%；PC1 也不是最能分的方向——沿 PC1 单阈值最优 BA 0.7123，沿类别均值差方向 0.9281，|cos| 仅 0.3841。UMAP 侧，只改种子（42→7）后 10 近邻 Jaccard 只有 0.606，只改 `n_neighbors=5` 只有 0.499，四次运行坐标范围互不相同，连通分量数从 1 跳到 4。
- **推理**：降维图展示的是“算法在二维里保住了什么”，不是“数据里有什么因果结构”。轴方向、簇位置、面积与间距由参数和随机性共同决定；PCA 还受“方差最大 ≠ 判别力最强”的限制。因此图上的分离只能升级为关于样本结构的假设，不能反推机制，也不等价于对未见样本的预测表现。
- **边界**：以上结论限定在 Golub 数据 72 样本、一次测量、逐列 z-score、欧氏距离、无批次字段、无外部队列的条件下；UMAP 只做三个单因素对照，没有参数搜索，也没有多批次重复。
- **额外验证**：在一个含批次信息的独立队列上固定同一套预处理与模型（全部折内拟合），检验（a）分组结构能否重现、（b）在从未参与分析与选参的外部样本集上预测表现能否复现。

## 课后三道作业（用自己的话）

**1. PCA 第一主成分代表什么？结合本次解释率和一个探针权重回答。**

第一主成分是这样一个方向：把每个样本的 7129 个探针值先各自标准化，再按这个方向的权重加权求和，得到的分数在样本之间变化最大——是“投影后方差最大”的一维方向，不是最有生物学意义的方向。本次 PC1 解释总方差的 **14.92%**，PC2 再解释 9.45%，两者合计 24.37%，也就是说前两轴合起来还不到四分之一。这个方向上权重绝对值最大的是探针 `X92518_s_at`，权重 **+0.028786**；符号为正表示它与 PC1 得分同向变化，但符号取决于 SVD 的任意朝向，整体翻号不改变结果。需要强调的是，0.0288 只是 7129 项里的一个系数，把权重前 5 的探针单独加起来也只复现样本 G001 得分的 0.5%，所以不能把“PC1 上权重最大”读成“这个探针最重要”。

**2. 为什么 PCA 前通常需要标准化？结合原尺度对照说明它的作用与代价。**

因为 PCA 找的是方差最大的方向，而原尺度下各列方差差了几个数量级：本数据列方差最小 7.032×10²、中位数 3.386×10⁴、最大 2.491×10⁸，最大是最小的约 **35.4 万倍**。不标准化时，原尺度 PC1 几乎被方差最大的几列牵着走——前五权重是 `M25079_s_at`(+0.3524)、`hum_alu_at`(+0.3136) 等，与标准化后的前五**零重叠**；原尺度 PC1 解释率 17.43%，看着比标准化的 14.92% 更高，但那只是同一批大方差列的重复。标准化的作用是让各列权重可比，主成分反映**相关结构**而不是量纲。代价是：低变异列被放大到与真实信号列同权，若低变异主要是测量噪声，噪声也会被一起放大。本次还观察到一个反向的代价——标准化 PC2 的单阈值 BA 只有 0.4894，而原尺度 PC2 有 0.9494，说明大方差列里确实顺带带着判别信息，标准化把它稀释了。因此两种口径都保留、写明差异，并且仍然认为要判断口径优劣必须在训练折内拟合、在独立样本上比较，而不是看同一批样本的事后 BA。

**3. UMAP 图能说明什么，不能说明什么？结合一次参数或种子对照说明。**

UMAP 图能说明：在这套参数下哪些样本被放进了同一个局部邻域，从而提示可能的分组或连续梯度，用于提出假设。它不能说明亚型数量、机制，也不能说明对新患者的预测能力——嵌入是“尽量保住近邻图”的优化结果，轴无含义、岛间距无标尺，且随参数与随机性变化。证据：同一份标准化矩阵，只把种子从 42 改成 7，10 近邻集合的 Jaccard 一致度只有 **0.606**，坐标范围从 x∈[−4.39, 0.06] 整体移到 x∈[7.29, 11.62]；只把 `n_neighbors` 从 15 改成 5，Jaccard 只有 **0.499**，而 kNN 图的连通分量数从 1 跳到 4（k=3），多出来的正是那个 8 点、100% ALL 的孤岛。也就是说，岛的个数和位置本身就是参数的产物，不能挑一张最好看的图当结论。
