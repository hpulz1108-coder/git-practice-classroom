# 数据使用建议书

## 最终方案
选择方案B：保留四中心全部记录，修正编码与可疑值后分层合并使用。可描述对象为UCI四中心920条心脏病历史诊疗记录，不能等同于920名独立患者。

## 核心证据
1. **变量类型**：年龄、血压、胆固醇、最大心率、ST下降为连续量；胸痛、灌注、静息心电图为无序分类；结局采用num>0二分类。
2. **分析方法**：连续量用均值描述，分类变量用列联表与卡方检验，二分类结局适配Logistic回归；无序类别不可直接求均值。
3. **数据质量**：全表共1759个缺失值，ca、thal缺失率超50%；胆固醇存在172个零值，各中心阳性率差异显著，不可直接删除缺失行。
4. **处理后果**：删除全部缺失仅余299条记录，其中Cleveland占99.3%，会完全改变研究人群构成。

## 边界与限制
当前数据无法回答12个月随访、疾病分期、单细胞基因、影像类问题；不能证明因果关系、现患率或临床部署可行性。

## 继续核查项
1. 胆固醇、静息血压零值是否为缺失哨兵值
2. ca、thal高缺失的原因与缺失机制
3. 各中心测量流程与编码一致性
4. 跨中心患者身份去重

## 停止条件
若证实零值为缺失且无法恢复、缺失与结局高度相关、或存在大量重复患者，则改选方案C或暂停分析。
