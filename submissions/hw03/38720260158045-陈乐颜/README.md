## 一、最终判断

我不赞同“特征越多模型一定越好”。本次真实表达数据中，距离的相对分布随探针数增加而集中，但固定历史测试划分的1近邻 BA 也随探针数增加而提高。说明更多探针可能提供额外信号，不能一概视为噪声；但一次小型历史测试划分不足以证明对新患者泛化。

## 二、关键证据

- **距离：** seed=42 时，p=2 与 p=7,129 的平均距离分别为1.268799和118.196488，CV分别为1.232761和0.186976，R中位数分别为115.451967和0.966904。平均距离增大而相对离散缩小并不矛盾；绝对尺度同时变大。
- **泛化划分：** 原38/34划分上，训练 BA 在五个维度均为1.000；测试 BA 从p=2的0.496429升至p=7,129的0.760714。p=7,129时 ALL 为19/20、AML 为8/14，恒预测 ALL 的 BA 基线为0.500。
- **训练内重复验证与稳定性：** 3折×3重复中，全部探针验证 BA 均值0.844（范围0.694–1.000）；折内筛20个探针均值0.886（范围0.750–1.000），但不是每折都更好。筛选集合 Jaccard 中位数0.270（范围0.143–0.429）。

## 三、适用边界

数据共有72份表达样本、7,129个探针，p/n约99.014；教学编号不是可核验的患者编号。数据没有探针到基因映射，故不能给出不同基因的精确数量。当前测试结果描述指定模型、划分和特征顺序，不等于新患者或临床验证；缺少患者重复映射、中心及批次信息，也限制了伪重复和批次效应判断。特征数改变时所选探针内容也改变，不能把所有结果差异只归因于维度。
